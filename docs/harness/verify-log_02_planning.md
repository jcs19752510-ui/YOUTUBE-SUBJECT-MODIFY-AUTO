## 1차 검증 (작성자 관점)
- 체크리스트: 입력 계약 반영, 출력 계약 10개 섹션 + 추적표, 상위 산출물 모순, 가정 표시, 구조 결함, 오탈자
- 스크립트 결과와 본문 점검에서 발견된 결함 (4건)
  1. 위험도 요약 문단이 엉망이고(건수 서술 오류), PRD §7의 건수(상 6·중 7·하 4)가 실제 표(상 7·중 8·하 2)와 불일치
  2. NFR 표가 목록 안에 들어가 마크다운 표로 렌더링되지 않을 수 있고 파서도 인식하지 못함
  3. SEC-001, SEC-003, SEC-007, POL-003이 어떤 위험의 완화 수단으로도 연결되지 않음
  4. NFR-006(요청 본문 구성 모듈 커버리지)이 WU-4에 배정되지 않음
- 조치: 건수를 파서로 재계산해 교정, NFR 표를 6-1로 분리, 위험 완화에 SEC/POL 연결, WU-4에 NFR-006 추가 → v1

## 2차 검증 (독립 심사자 관점 — "이 기획서만 보고 설계서를 쓸 아키텍트")
- 발견된 결함 (3건)
  1. **숨은 의존성**: FR-004(제목-내용 일치)는 영상 설명이 필요한데 설명은 WU-2의 조회 결과이고 WU-3은 WU-2에 의존하지 않는 것으로 되어 있었음
  2. 성과 비교(FR-018)에 필요한 "변경 전 지표"를 적용 전에 확보하라는 요구가 없음
  3. NFR-009가 데이터 삭제 명령을 요구하는데 CLI 서브커맨드(FR-017)에 없음
- 조치: `description_excerpt` 선택 필드와 DB 대체 경로 추가, FR-012에 기준선 스냅샷 확인 추가, `purge` 추가, 가정 10·11 추가 → v2

## 3차 검증
- 발견된 결함 (2건)
  1. 4-2에서 "비목표"라고 불렀으나 절 이름은 Out-of-Scope
  2. **금칙어 우회 표기**(띄어쓰기·기호 삽입)를 막는 요구가 없음 (안전 필터의 실질 빈틈)
- 조치: 문구 교정, FR-003에 정규화 매칭과 우회 표기 테스트 요구 추가 → v3

## 4차 검증
- 방법: 수정 후 §7-1, §8, §9, §11을 처음부터 다시 읽음, 스크립트 재실행
- 발견된 결함 (1건)
  1. 검증 중에 고친 내용이 PRD 변경 이력에 기록되지 않음
- 조치: 변경 이력 v1~v4 기록 → v4

## 5차 검증 (결함 0건 확인)
- 방법: 스크립트 재실행 — ID 수 FR 20·NFR 9·POL 4·SEC 13·RISK 17·OOS 6, 작업단위 미배정 0, §9의 미정의 ID 0, 위험 완화의 미정의 ID 0, 위험 완화에 쓰이지 않은 SEC/POL 0, 본문 참조 중 미정의 ID 0. 추적표 행 63개(+OOS 6개)가 `Not Started`로 생성됨
- 발견된 결함: 0건
