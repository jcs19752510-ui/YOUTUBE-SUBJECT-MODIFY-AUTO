# 파일 안내 색인 — 내부 테스트 결과서와 주요 파일

> 이 프로그램(유튜브 제목)은 유튜브 채널 '시니어 생활팁'의 영상 제목을 안전하게 바꾸는 도구입니다. 제목 후보를 검사하고, 사람이 승인한 것만 바꾸고, 기록하고, 되돌립니다. 각 항목의 **굵은 첫 줄**만 읽으면 무슨 파일인지 알 수 있습니다. 같은 내용을 보기 좋게 만든 아티팩트 페이지도 있습니다.

## 내부 테스트 결과서 (docs/harness/units/)

7개 모두 합격(PASS)입니다. 같은 번호의 검증 로그는 `docs/harness/verify-log_unit-N-test.md`에 있습니다. 실제 구글 연결 부분(실제 제목 변경, 실제 응답 형식)과 Windows 전용 동작은 이 테스트로 확인하지 못했고, 12단계에서 확인해야 합니다.

### unit-0-test.md — WU-0 공통 기반
**모든 기능이 함께 쓰는 바닥 부품(설정, 기록 남기기, 저장소, 시간, 화면 표)을 시험한 결과서입니다.**

- 테스트 108개 · 변이 점검(코드를 일부러 망가뜨려 시험이 잡는지 확인) 23/23 · 커버리지 95%
- 확인한 것:
  - 설정 파일을 읽고, 위험한 설정은 거부하는지
  - 비밀번호·토큰이 기록과 화면에 절대 나오지 않는지
  - 구글 호출이 실패하면 최대 2번만 다시 시도하는지
  - 데이터 저장소(7개 표)와 백업, 오래된 기록 삭제(purge)
  - 하루 기준을 미국 태평양 시간으로 정확히 계산하는지
  - 화면에 상태를 글자와 기호로 보여 주는 부품

### unit-1-test.md — WU-1 구글 로그인
**구글 로그인(OAuth)을 시험한 결과서입니다. 읽기용 로그인과 쓰기용 로그인을 따로 쓰는 것이 핵심입니다.**

- 테스트 26개 · 변이 점검(코드를 일부러 망가뜨려 시험이 잡는지 확인) 13/13 · 커버리지 99%
- 확인한 것:
  - 읽기 권한과 쓰기 권한의 로그인 정보를 분리해 저장하는지
  - 로그인 정보 파일 권한을 본인만 볼 수 있게 제한하는지
  - 로그인 정보가 없거나 깨졌을 때 한국어로 안내하는지
  - 로그인 정보를 모두 지우는 기능(--revoke)

### unit-2-test.md — WU-2 영상·성과 조회와 하루 사용 한도
**내 채널 영상과 성과 숫자를 읽어 오는 기능과 구글 하루 사용 한도(쿼터) 관리를 시험한 결과서입니다.**

- 테스트 178개 · 변이 점검(코드를 일부러 망가뜨려 시험이 잡는지 확인) 32/32 · 커버리지 99%
- 확인한 것:
  - 영상 정보를 읽기 전용으로만 조회하는지(영상은 절대 안 바뀜)
  - 쓰기 전에 하루 사용량을 미리 잡아 두고, 한도를 넘기지 않는지
  - 구글이 한도 초과나 권한 오류를 돌려줄 때 알맞게 안내하는지
  - 노출수·클릭률을 못 받으면 Studio CSV를 쓰라고 안내하는지

### unit-3-test.md — WU-3 제목 후보 입력과 안전 검사
**제목 후보 파일을 읽고 '이 제목을 써도 안전한가'를 판정하는 기능을 시험한 결과서입니다.**

- 테스트 146개 · 변이 점검(코드를 일부러 망가뜨려 시험이 잡는지 확인) 34/34 · 커버리지 100%
- 확인한 것:
  - 길이 제한, 과장·공포 조장·의료 효능 단정 같은 금칙어 걸러내기
  - 영상 내용과 제목이 얼마나 맞는지(일치율) 계산
  - 건강·금융 주제는 엄격 모드로 경고도 차단하는지
  - 후보 파일이 잘못되었거나 악의적이어도 안전하게 거부하는지

### unit-4-test.md — WU-4 변경 계획·기록·되돌리기 계획
**'제목을 바꾸면 무엇이 달라지는지' 계획을 세우고, 변경 기록을 남기고, 되돌리기 계획을 세우는 기능을 시험한 결과서입니다.**

- 테스트 241개 · 변이 점검(코드를 일부러 망가뜨려 시험이 잡는지 확인) 47/47 · 커버리지 100%
- 확인한 것:
  - 제목 외 설명·태그·카테고리가 그대로 유지되는지
  - 너무 자주 바꾸지 못하게 하는 제한(72시간 간격, 영상당 3회, 하루 3건, 노출수 1,000회)
  - 계획이 바뀌면 달라지는 '계획 해시'(지문)가 제대로 만들어지는지
  - 승인 없이는 기록도 상태 변경도 못 하는지
  - 되돌리기 계획이 원래 제목을 정확히 복원하는지

### unit-5-test.md — WU-5 승인과 실제 반영 안전장치
**사람의 승인과 14단계 안전 게이트를 거쳐 실제로 제목을 바꾸거나 되돌리는 가장 위험한 부분을 시험한 결과서입니다.**

- 테스트 278개 · 변이 점검(코드를 일부러 망가뜨려 시험이 잡는지 확인) 93/93 · 커버리지 100%
- 확인한 것:
  - 승인 파일이 위조·만료·재사용·다른 영상 용도로 쓰이지 못하는지
  - 14단계가 정해진 순서로, 하나라도 막히면 즉시 멈추는지
  - 영상 ID를 사람이 직접 입력해야만 진행되는지
  - 구글 호출 도중 오류가 나도 기록이 맞게 남는지(확실한 실패 / 알 수 없음 구분)
  - 바꾼 뒤 다시 읽어 제목이 반영되고 설명·태그가 보존됐는지 확인
  - 제목을 바꾸는 코드가 프로젝트 전체에서 딱 한 곳뿐인지

### unit-6-test.md — WU-6 성과 비교 리포트와 CSV 가져오기
**제목을 바꾼 전후의 노출수·클릭률·조회수를 비교해 보여 주는 리포트와 Studio CSV 가져오기를 시험한 결과서입니다.**

- 테스트 147개 · 변이 점검(코드를 일부러 망가뜨려 시험이 잡는지 확인) 71/71 · 커버리지 100%
- 확인한 것:
  - CSV의 한글·영문 머리글을 알아보고, 엑셀 수식 같은 위험한 값은 막는지
  - UTF-8·엑셀 한글(CP949)·UTF-16 인코딩을 읽는지, 5MB·1만 행 제한
  - 자료가 부족하면 억지로 결론 내지 않고 '데이터 부족'이라고 하는지
  - 제목 때문이라고 단정하지 않고 다른 요인이 있다는 문구가 항상 붙는지

## 프로그램 부품 (src/ytitle/)

### 입구와 공통 부품

| 파일 | 하는 일 |
|---|---|
| `cli.py` | 명령어의 입구입니다. 어떤 명령을 쳐도 여기를 먼저 지나며, 오류를 한국어로 바꾸고 실행 기록을 남깁니다. |
| `config.py` | 설정 파일(config/settings.yaml)을 읽고 값이 올바른지 확인합니다. |
| `errors.py` | 오류 종류를 정의합니다. 모든 오류 메시지에 '다음에 할 일'이 붙습니다. |
| `logging_setup.py` | 기록(로그)을 남기되 비밀번호와 토큰은 별표로 가립니다. |
| `db.py` | 내 컴퓨터의 데이터 저장소(SQLite)를 만들고 관리합니다. 변경 기록, 후보, 지표가 여기에 저장됩니다. |
| `retry.py` | 구글 호출이 실패하면 최대 2번까지만 다시 시도합니다(무한 반복 금지). |
| `timeutil.py` | 시간 계산을 맡습니다. 구글 하루 한도는 미국 태평양 시간 기준이라 이를 정확히 다룹니다. |
| `textsafe.py` | 제목·설명 같은 바깥에서 온 글자를 안전하게 정리합니다(숨은 제어문자 제거, 글자 수 세기). |
| `ui.py` | 터미널 화면에 표, [통과]·[차단] 표시, 오류 안내, 영상 ID 입력 확인을 그려 줍니다. |
| `platform_utils.py` | Windows와 Linux의 차이를 한곳에 모아 둡니다(파일 권한, 한글 출력). |

### 구글 연결

| 파일 | 하는 일 |
|---|---|
| `auth.py` | 구글 로그인을 처리합니다. 읽기용과 쓰기용 로그인 정보를 따로 저장합니다. |
| `youtube_read.py` | 내 채널의 영상 정보와 성과 숫자를 읽기 전용으로 가져옵니다. |
| `quota.py` | 구글 하루 사용 한도를 미리 잡아 두고, 넘지 않게 막습니다. |

### 제목 후보 검사

| 파일 | 하는 일 |
|---|---|
| `candidates.py` | 제목 후보 파일(candidates 폴더)을 읽고 형식이 맞는지 검사합니다. |
| `banned_terms.py` | 쓰면 안 되는 표현 사전(config/banned_terms.yaml)을 읽습니다. |
| `validator.py` | 후보 제목이 통과·경고·차단 중 무엇인지 판정합니다(길이, 금칙어, 영상과의 일치율). |

### 변경 계획과 기록

| 파일 | 하는 일 |
|---|---|
| `updater.py` | 제목을 바꾸면 무엇이 달라지는지 계획을 계산합니다. 계산만 하고 아무것도 바꾸지 않습니다. |
| `limits.py` | 너무 자주 바꾸지 못하게 하는 4가지 제한을 검사합니다. |
| `history.py` | 제목 변경 기록을 남기고, 후보 상태를 관리하고, 되돌리기 계획을 세웁니다. |

### 실제 반영 안전장치

| 파일 | 하는 일 |
|---|---|
| `approvals.py` | 사람의 승인 파일을 만들고 검사합니다. 위조 방지 서명, 만료, 1회용 규칙이 여기에 있습니다. |
| `live_guard.py` | 14단계 안전 게이트와 실제 제목 변경 호출이 있는 파일입니다. 유튜브 제목을 바꾸는 코드가 프로젝트 전체에서 이 파일 한 곳에만 있습니다. |

### 성과 리포트

| 파일 | 하는 일 |
|---|---|
| `report.py` | 제목 변경 전후의 숫자를 계산해 비교합니다. 자료가 부족하면 결론을 내지 않습니다. |
| `csv_import.py` | Studio에서 내보낸 CSV 파일을 안전하게 읽어 저장합니다. |

## 명령어 파일 (src/ytitle/commands/)

| 파일 | 이 명령이 하는 일 |
|---|---|
| `validate.py` | validate: 제목 후보를 검사해 통과·경고·차단으로 나눠 보여 줍니다. 아무것도 바꾸지 않습니다. |
| `plan.py` | plan: 이 후보로 바꾸면 제목과 제한 검사가 어떻게 되는지 미리 보여 줍니다. 구글에 연결하지 않습니다. |
| `approve.py` | approve: 계획을 확인하고 영상 ID를 직접 입력하면 승인 파일을 만듭니다. |
| `apply.py` | apply: 제목을 바꿉니다. 옵션이 없으면 모의 실행, --live를 붙여도 14단계를 모두 통과해야 바뀝니다. |
| `rollback.py` | rollback: 바꾼 제목을 이전 제목으로 되돌립니다. 기본은 계획만 보여 줍니다. |
| `report.py` | report: 제목 변경 전후 성과를 비교합니다. --import-csv로 Studio CSV를 가져옵니다. |
| `fetch.py` | fetch: 내 채널의 영상과 성과 숫자를 읽어 옵니다(읽기 전용). |
| `auth.py` | auth: 구글 로그인 상태 확인, 읽기/쓰기 로그인, 로그인 정보 삭제. |
| `purge.py` | purge: 오래된 기록을 지웁니다. 기본은 미리보기이고 지우기 전에 백업합니다. |

## 진행 관리 문서 (docs/harness/)

| 파일 | 무슨 문서인지 |
|---|---|
| `STATE.md` | **지금 어디까지 했는지 적은 진행 상황** 세션이 끊겨도 이 파일만 읽으면 이어서 작업합니다. 결정 대기 항목과 다음 순서가 있습니다. |
| `decisions.md` | **무엇을 왜 결정했는지 적은 결정 일지** 번호(DEC-001~)를 붙여 한 줄씩 기록합니다. 한번 쓴 줄은 지우지 않습니다. |
| `traceability.md` | **요구사항이 시험까지 이어졌는지 보는 추적표** 기획서의 요구사항마다 담당 코드와 시험 번호를 적어 빠진 것이 없는지 확인합니다. |
| `units/unit-N-note.md` | **각 작업 단위의 개발 노트** 무엇을 만들었고, 설계와 달라진 점과 이유, 사용자에게 묻고 싶은 것을 적었습니다. |
| `units/unit-N-test.md` | **각 작업 단위의 내부 테스트 결과서** 위의 '내부 테스트 결과서' 7개입니다. |
| `verify-log_*.md` | **산출물을 최소 2번 검증한 기록** 문서와 시험마다 1차·2차·결함 0건 확인 과정을 남겼습니다. |

이 검증은 법률 자문이 아니며 최종 책임은 채널 소유자에게 있습니다.
