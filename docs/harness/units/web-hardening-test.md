4. 시험 5건이 이전 세션에서 갱신되지 않은 사실은 **내 검증 누락**이었다(백엔드 매트릭스만 돌리고 `tests_infra`/`tests_security`는 돌리지 않음). 이후 최종 시험에 두 폴더를 포함한다.
5. 인프라·보안 전체에서 건너뜀 427(Docker·실서버 필요 시험)은 합격으로 세지 않았다.
