# unit-3 구현 노트 — WU-3 후보 입력·안전 필터 (5단계)

- 작업 단위: **WU-3** (feature F-B 후보·필터) / **속도 트랙: L3** / Tier: Standard / 선행: WU-0(완료)
- 실행: **병렬 웨이브A**에서 WU-2와 동시에 진행(WU-2는 서브에이전트, WU-3은 오케스트레이터). 파일 범위 겹침 없음 확인.
- 파일 범위: `src/ytitle/{candidates,validator,banned_terms}.py`, `src/ytitle/commands/validate.py`, `config/banned_terms.yaml`, `tests/test_{candidates,banned_terms,validator,validate_cmd}.py`

## 1. 구현 범위
후보 파일 읽기·입력 검증(경로 조작 방지 포함), 금칙어 사전 읽기·검증·해시, 제목 검증기(길이·규격·금칙어·경고 유형·영상 일치율·근거 문장·핵심어 위치·엄격 모드), 검증 결과 DB 기록, `validate` 명령(SCR-002).

## 2. 설계서 대비 편차와 사유
| # | 편차 | 사유 |
|---|---|---|
| 1 | `validate --file`의 상대 경로는 **프로젝트 폴더(--base-dir) 기준**으로 해석 | 현재 폴더 기준이면 `--base-dir`와 어긋남(테스트가 발견). |
| 2 | 영상 설명은 후보 파일의 `description_excerpt`를 우선, 없으면 DB `videos`(WU-2가 채움)에서 읽기 전용으로 조회 | 02 가정 10, WU-2에 직접 의존하지 않는 인터페이스. DB에 행이 없어도 동작. |
| 3 | 일치율 = 제목의 핵심 낱말 중 요약·설명(공백·기호 제거 후)에 포함된 비율. 조사는 단순 규칙으로 제거, 숫자 포함 낱말과 일반어(방법·꿀팁 등)는 제외 | 형태소 분석기를 쓰지 않기 위해(의존성 최소). **한계**: 동의어·어순 변형은 못 잡고, 2글자 낱말은 우연히 포함될 수 있음. |
| 4 | "핵심어는 앞 20자 이내" = 요약·설명에서 많이 나온 상위 5개 낱말 중 하나라도 제목 앞 20자에 있어야 함(없으면 경고 `KEY_LATE`) | 설계서에 핵심어 정의가 없어 가장 단순하고 설명 가능한 정의를 택함. |
| 5 | 이모지 판별은 유니코드 범위(그림 문자 + 장식 기호 ★ 등)로 보수적으로 셈 | 시니어 대상 과장 표현 억제 목적. |
| 6 | 같은 후보 파일을 다시 검증하면 (영상, 제목, 파일 해시)가 같은 행을 갱신하고, 승인 이후 단계의 행은 건드리지 않음. 파일 내용이 바뀌면 새 행 | 설계 3-2 상태 머신 보호. |
| 7 | 금칙어 사전 초기 내용은 오케스트레이터가 작성한 **초안**이며 법률 검토를 거치지 않음 | POL-002. 유형별 예시이고 전부가 아님. |

## 3. 인수 조건 (AC)
| AC | 인수 조건 | 연결 요구 |
|---|---|---|
| AC-01 | 후보 파일을 읽고 필드·형식·크기(256KB)·후보 수(1~20)를 검증하며 BOM은 허용, UTF-8이 아니면 저장 방법을 안내하고, 오류는 한 번에 모두 알려 준다 | FR-001, EVT-201 |
| AC-02 | 경로 조작 방지: candidates 폴더 바로 아래만, 파일 이름은 영상 ID 형식이고 `video_id`와 일치, 심볼릭 링크 탈출 거부 | SEC-011, RISK-010 |
| AC-03 | 금칙어 사전: 로드·검증(짧은 단어/잘못된 정규식/알 수 없는 키 거부), 위험한 YAML 태그를 실행하지 않음, 내용 해시가 변경을 반영 | FR-003, SEC-016, SEC-017 |
| AC-04 | 차단: 5가지 금칙어 유형, 길이 상한 초과, `<` `>`·제어문자·빈 제목, 영상과 일치율 매우 낮음, **우회 표기(공백·기호·전각·제로폭·자모 분리)도 차단** | FR-002, FR-003 |
| AC-05 | 경고: 느낌표·이모지·반복 기호·대문자·기호 비율·권장 길이 초과·핵심어 위치·현재와 같은 제목·근거 문장 미확인 | FR-002 |
| AC-06 | 경계값: 40/41/100/101자, 일치율 50%/25%, 느낌표 1개·이모지 2개 | FR-002, FR-004 |
| AC-07 | 엄격 모드(건강·금융·주제 미지정·건강/금융 낱말 감지)에서는 경고도 차단이며 사유에 표시 | POL-001 |
| AC-08 | 영상 일치 점검: 요약+설명 기반 일치율, 근거 문장이 요약·설명에 실제로 있는지 확인, 설명 사용 여부 표시 | FR-004 |
| AC-09 | 리포트(SCR-002): 영상·주제·사전 버전/해시·결과 배지·사유·요약·면책 문구, `--plain` | FR-005, POL-002 |
| AC-10 | DB 기록: 상태(filtered/blocked)·사전 해시·사유, 재검증 시 중복 방지, 승인 이후 행 불변 | SEC-017 |
| AC-11 | 명령: `--file`/`--all`/빈 폴더/옵션 없음/폴더 밖 파일 거부/필드 오류, 외부 문자열 정화, 네트워크·쓰기 호출 코드 없음 | EVT-003, SEC-019, SEC-001 |
| AC-12 | 후보 100건 검증 5초 이내, 검증은 입력을 바꾸지 않음 | NFR-005 |
| AC-13 | 한글 통과 케이스 12건 이상, 차단 케이스 10건 이상(v1 YT-08 검증 기준) | FR-002 |

## 4. 수동 확인이 필요한 부분
- **금칙어 사전의 법적·정책적 적절성**은 사용자가 검토해야 한다(법률 자문이 아님).
- 실제 채널 영상으로 한 번 돌려 **과차단/과소차단**(예: "속보 걷기 운동"이 차단되는 사례, TC-338)을 보고 사전을 조정해야 한다.
- 일치율 휴리스틱의 정확도는 실제 제목·요약 표본으로 검증하지 못했다(합성 데이터만 사용).

## 5. 게이트 1 — 정적 분석
`py_compile`, `pyflakes` 통과. 린터 설정은 프로젝트에 없음(WU-0 노트 7절 질문과 동일).
