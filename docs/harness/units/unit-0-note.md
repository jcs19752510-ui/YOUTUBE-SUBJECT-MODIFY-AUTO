# unit-0 구현 노트 — WU-0 공통 기반 (5단계)

- 작업 단위: **WU-0** (feature F-0, 공통 선행 단위 unit-0) / **속도 트랙: L3** / Tier: Standard
- 실행: 단독 실행(이 환경은 서브에이전트 미사용, DEC-011). 동시에 도는 단위 없음
- 입력: `docs/yt/DESIGN.md` §1-3·§3·§4·§5·§6, `04_ux_design.md`, `02_planning.md` §9

## 1. 구현 범위
`pyproject.toml`, `requirements*.txt`, `.gitignore`(비밀 항목 추가), `config/settings.yaml`, `src/ytitle/` 아래 `config`, `logging_setup`, `errors`, `retry`, `db`, `timeutil`, `platform_utils`, `textsafe`, `ui`, `cli`, `__main__`, `commands/purge.py`, 그리고 `tests/` (conftest 포함 11개 파일).

## 2. 설계서 대비 편차와 사유
| # | 편차 | 사유 |
|---|---|---|
| 1 | `title_changes`에 `created_at` 컬럼 추가 | `purge`의 보관 기준 시각이 필요(설계 3-1에는 `applied_at`만 있어 `planned` 행은 NULL). |
| 2 | `title_candidates.video_id`, `title_changes.video_id`에 `videos` 외래키를 걸지 않음 | WU-3(후보 검증)이 WU-2(조회)에 의존하지 않도록(FR-004, 02 가정 10). `candidate_id` 외래키는 유지. |
| 3 | `purge`는 기본 미리보기이고 `--execute` + '삭제' 입력이 있어야 실제 삭제 | 설계 §3-4의 "확인 요구"를 더 보수적으로 구현. |
| 4 | 버전은 `0.0.0`(임시) | 부록 C: 버전 번호는 에이전트가 정하지 않고 사용자 질문 13에 따름. |
| 5 | 숨김 전역 옵션 `--base-dir` 추가 | 테스트와 다른 폴더 실행을 위해. 도움말에는 나오지 않음. |
| 6 | 마이그레이션을 명시적 `BEGIN/COMMIT`으로 감쌈 | sqlite3는 DDL을 자동으로 트랜잭션에 묶지 않아 중간 실패 시 반쪽 DB가 남는 결함을 테스트가 잡음(TC-076). |
| 7 | 호환 Python은 3.11·3.12·3.13에서 검증, **3.10은 미검증** | 이 환경에 3.10이 없음. `requires-python >=3.10`은 선언만 했고, 3.10 검증은 8단계 전 확인 필요. 설계서 2장의 "테스트 환경은 3.13" 서술은 이번에 3.11/3.12도 쓸 수 있음이 확인되어 정정 대상. |

## 3. 인수 조건 (Acceptance Criteria) — 6단계 테스터가 쓰는 기준
| AC | 인수 조건 | 연결 요구 |
|---|---|---|
| AC-01 | `python -m ytitle --help`가 `commands/` 아래 모듈을 자동 탐색해 표시한다(WU-0 시점에는 `purge`, 파일 추가 시 목록에 나타남) | FR-017, ADR-003 |
| AC-02 | 기본은 dry-run이다: 쓰기 명령이 아닌 명령에는 `--live`가 없고 실행 기록의 모드는 `dry_run` | SEC-001 |
| AC-03 | 설정 로드: 기본값, 파일 우선순위, 범위·형식 검증(한국어 오류), `enable_live`/`live_allowlist`는 `settings.local.yaml`에서만 적용, 위험한 YAML 거부 | NFR-003, SEC-001, SEC-012, SEC-016 |
| AC-04 | 로그·예외·콘솔에서 토큰·키 형식이 가려지고 정상 한글·영상 ID는 가리지 않는다 | SEC-008, NFR-011 |
| AC-05 | 재시도는 최대 2회, 지수 백오프(1초→2초), 재시도 불가 오류는 즉시 중단 | SEC-003, NFR-004 |
| AC-06 | DB: 7개 테이블, 외래키·CHECK 제약, 마이그레이션 원자성·멱등, 파라미터 바인딩, 백업 사본, 새 버전 DB 거부 | ADR-002, SEC-018, NFR-010 |
| AC-07 | textsafe: ANSI·제어·방향 제어 문자 제거, 글자 수(유니코드), 우회 표기 정규화, 표시 폭 | SEC-019, FR-002, FR-003 |
| AC-08 | timeutil: 쿼터 날짜는 태평양 시간 기준(겨울/여름/서머타임 전환일 경계), tzdata 없으면 안내 | ADR-006, NFR-003 |
| AC-09 | `purge`: 미리보기는 삭제하지 않음, 실제 삭제는 확인 입력 후, 삭제 전 DB 사본, 영상별 최근 성공 변경 보존, 미래/잘못된 날짜 거부 | NFR-009 |
| AC-10 | ui 컴포넌트: 상태 배지(기호+글자), 한글 폭 정렬 표, plain 모드, 오류 블록, 영상 ID 직접 입력 확인(3회), 면책 문구 | SCR-002, UX-002, POL-002 |
| AC-11 | 전역 옵션(`--plain`, `--base-dir`)이 명령 앞·뒤 어디서든 적용되고 현재 폴더를 오염시키지 않는다 | FR-017 |
| AC-12 | 플랫폼 유틸: 토큰 폴더는 프로젝트 밖, 권한 제한(POSIX), UTF-8 설정이 예외 없이 동작 | ADR-004, SEC-008, NFR-002 |
| AC-13 | 오류 처리: `YtError` → 한국어 오류 블록과 종료 코드(안전 게이트 3), 알 수 없는 명령 2, Ctrl+C 130, 예상 못한 오류는 비밀 없이 안내하고 로그에 남김 | NFR-007, FR-020 |

## 4. 수동 확인이 필요한 부분 (이 환경에서 불가)
- Windows 고유: `icacls` 권한 제한, 실제 콘솔(cp949/UTF-8) 한글 표시, PowerShell 실행 정책, `%LOCALAPPDATA%` 경로. → TC-054는 "미수행(Windows 필요)".
- Python 3.10 호환(미검증).
- 로그 파일 5MB 회전은 테스트하지 않음.

## 5. 게이트 1 — 정적 분석/린트
- 프로젝트에 린터·포맷터·타입 검사 **설정이 없다**(설계서가 도구를 정하지 않음, 임의로 고르지 않음). 대체로 검증용 임시 환경에서 `py_compile`과 `pyflakes`를 실행했다: **통과**(미사용 import 4건을 발견해 수정). 린트 도구 도입 여부는 오케스트레이터 → 사용자 질문 대상(아래 7절).
- Python 3.11/3.12/3.13에서 컴파일·전체 테스트 실행: 통과. (3.12 전용 f-string 중첩 따옴표 1건을 발견해 수정 — 3.10/3.11 호환 선언 때문)

## 6. 게이트 2 — 자체 코드 리뷰 체크리스트
- [x] 설계서/UX 명세와 구현 일치 (편차는 2절에 사유와 함께 기록)
- [x] 에러 처리 누락 경로 없음. `except Exception`은 최상위 `main`에서 비밀을 가려 안내·로그하는 한 곳뿐이며, 이전에 있던 예외 삼킴(`except: pass`)은 제거하고 로그로 남기도록 수정
- [x] 입력 검증이 경계에서 이루어짐(설정 파일, CLI 인자 날짜, YAML safe_load)
- [x] 하드코딩 비밀 없음(`ya29.` 등 패턴 검색: 마스킹 패턴 정의 외 없음)
- [x] 신규 의존성 6종은 PyPI 실존·라이선스를 설계 단계에서 조회했고 설치로 재확인함. pyflakes는 검증용 임시 설치이며 프로젝트 의존성이 아님
- [x] 범위 밖 변경 없음 (`.gitignore` 추가는 WU-0 소유 범위)
