# 01 조각 — 축 C: AI 제안 기능 · 규제 · YouTube Studio 중복

- 조사 시점: 2026-10-10 (모든 "확인 일자"는 이 날짜). 모드: 조각(축 C 전용). 검색 모드: standard.
- 적용 법규 기준: 대한민국 + YouTube/Google 약관 (DEC-032). 업무 유형: 기능 추가(구조 전환), Tier High (규칙 I·J 해당).
- **법률 자문이 아니다.** 아래 법령 해석은 2차 자료(로펌 뉴스레터·기사·블로그)의 검색 요약에 의존하며, 에이전트가 법적 판단을 대신하지 않는다.
- **열람 한계(중요)**: 공식 원문(`support.google.com`, `genai.owasp.org`, `owasp.org`, `law.go.kr`)과 일부 2차 자료(`shinkim.com`, `socialmediatoday.com`) 열람을 `WebFetch`로 시도했으나 **전부 DNS 해석 실패(`getaddrinfo ENOTFOUND`)**로 열람 0건이다. 아래 모든 근거는 `WebSearch` 요약뿐이므로 해당 항목에 "[확인 필요: 원문 미열람]"이 적용된다. 표의 "열람 여부"는 모두 "검색 요약만"이다.

## 1. 요약 (5줄)
1. AI 기능은 규칙 J에 해당한다. 영상 제목·설명(외부 입력)이 LLM에 전달되고, 생성 제목은 사람이 승인해야 반영되는 구조이므로 **LLM에는 도구/API 권한을 주지 않는 "텍스트 생성기" 역할로 한정**하는 것이 핵심 완화책이다. 프롬프트 인젝션은 NCSC(2025-12)가 "완전한 방어는 어려울 수 있다"고 경고하므로 구분자·필터에 의존하지 말고 **영향 범위 축소(권한 없음, 사람 승인, 기존 검증기)**로 설계한다.
2. AI 기본법은 2026-01-22 시행(2차 자료 다수 일치). 투명성 의무(제31조)의 주체는 AI 제품·서비스를 이용자에게 제공하는 "인공지능사업자"로 설명되며, 본 도구(채널 소유자 1인 로컬 사용)가 해당하는지는 **확인 필요**이다. 고영향 AI(11개 분야 보도)에 제목 제안은 해당 가능성이 낮아 보이나 단정하지 않는다.
3. 외부 AI로 영상 설명을 보낼 때 이름·연락처가 섞이면 개인정보 이슈와 국외 이전(개인정보 보호법 제28조의8) 쟁점이 생길 수 있다. 개인 채널 운영자가 "개인정보처리자"인지는 사안별이라 **확인 필요**. 보수적 설계: 전송 전 연락처·이메일·전화번호 패턴 마스킹 + 사용자 고지.
4. 건강·금융 주제 제목은 식품표시광고법(질병 예방·치료 오인 금지)·자본시장법(유사투자자문 손실보전·이익보장 오인 금지, 2024-08-14 시행)에 닿고, YouTube는 오해 소지 메타데이터/낚시성 제목 단속을 강화하는 추세다. **AI로 쓴 제목 자체에 대한 YouTube 공개/표시 요구는 찾지 못했다**(변형·합성 콘텐츠 공개 규정은 "현실로 오인될 영상 콘텐츠"가 대상으로 요약됨).
5. Studio 제목 A/B 테스트(최대 3안, PC 전용, 시청 시간 기준)는 "공식 효과 검증"이고 본 도구는 "일괄 제안·승인·반영·롤백"이라 역할이 다르다. **A/B 테스트 API는 찾지 못했다(없음 증명 아님 → 확인 필요).** 테스트 진행 중 API로 제목을 바꾸면 어떻게 되는지도 미확인이므로 충돌 방지 규칙이 필요하다.

- 요청: 영상 1건당 1회 호출, 입력은 제목+설명 요약(길이 상한)만. 시스템 지시와 영상 데이터를 역할/구획으로 분리하되 **분리는 보안 경계가 아니라 품질 보조**로 취급.
- 응답: JSON 스키마 `{candidates:[{title, reason}]}` 강제, 파싱 실패·스키마 불일치·후보 수 초과는 폐기. 각 title은 기존 검증기(길이 100자, `<` `>` 금지, 금칙어, 영상 일치, 엄격 모드)를 통과해야 후보로 저장.

- 테스트: 모의 AI 서버(정상, 형식 깨짐, 지연, 오류, 인젝션 문구 포함 응답)로만 검증. 실제 호출은 사용자 승인 후.
