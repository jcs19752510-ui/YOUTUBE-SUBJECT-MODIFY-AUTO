# 통합 테스트 결과서 — feature `web-m1` (웹 전환 M1 데모 모드 전체 스택)

> 템플릿: `templates/test-report-template.md` (전 섹션). 수행하지 못한 것은 "미수행(사유)"로 구분하고 PASS 로 세지 않았다. 판정은 9절.

## 1. 개요
- 테스트 대상: 업무단위(feature) `web-m1` 전체. 작업 단위 W-BE-A(백엔드 기반), W-BE-B(백엔드 도메인), W-FE(프런트), W-INF(인프라)를 **실제 컨테이너 5개**(db·migrate·api·worker·web/nginx)로 조립한 전체 스택
- 테스트 유형: 통합(단위 간 데이터 흐름·상태 전이·경계·실브라우저 E2E·인프라 실가동). 단위 테스트 반복 없음
- 적용 Tier: High 상당(웹·승인·감사·실제 제목 변경 도구) — 별도 Tier 지정 입력이 없어 `traceability`/STATE 의 기존 취급을 따랐다(가정)
- 적용 속도 트랙: N/A (L1 부채 표시 없음, 정식 절차)
- 병렬 실행 정보: 병렬 웨이브에서 실행(동시: 9단계 보안 에이전트, 프로젝트 `harness-tmp-sec`·포트 18380). 이 실행은 `harness-tmp-int*` 자원과 포트 127.0.0.1:18080 만 사용했고 `harness-tmp-sec*` 은 건드리지 않았다. 도중에 세션 한도로 중단돼 재개했고 그 사이 Docker 엔진이 재시작됐다(아래 7절)
- 테스트 목적: 6단계에서 각각 통과한 4개 단위가 조립됐을 때 깨지는 곳이 없는지(승인 → 배치 → 워커 → 이력 → 롤백 → 리포트 → 감사의 값 흐름, 재시작·kill·DB 재시작 경계, 입력 경계 계층, 백업·복원·마이그레이션, 화면)를 실가동으로 확인하고, 6단계 조건부 PASS 항목(W-FE, W-INF)을 닫는다
- 관련 산출물: `docs/yt/WEB_DESIGN.md`(§4 동작 규칙), `docs/yt/API.md`, `docs/yt/WEB_RUNBOOK.md` 13-1(C-1~C-10), `docs/harness/units/web-WU-{BE-A,BE-B,FE,INF}-test.md`, `web/README.md`, 시험 코드 `web/tests_integration/`·`web/tests_infra/`
- 테스트 수행자(에이전트): 07 업무단위 통합 테스터(QA/DevOps)
- 테스트 일시: 2026-10-11 (저장소 최신 커밋 02ec286 기준 코드로 이미지를 새로 빌드)

## 2. 테스트 범위 및 제외 범위
- 범위 (In-Scope)
  1. **단위 간 데이터 흐름·상태 전이**: 모의 유튜브 시드(BE-B) ↔ 영상 목록 ↔ 제안 ↔ 승인(HMAC·24시간·1회용) ↔ 배치 사전 점검 ↔ 실행 확인 문구 ↔ 워커 ↔ 변경 이력 ↔ 롤백 ↔ 리포트·CSV ↔ 감사 해시 체인(4-3 표, IT-INT 의 IT-100번대 시나리오), 일일 상한 변경의 대기열 반영, 영상당 한도(72시간·3회) 일관성
  2. **경계**: api·워커 재시작·SIGKILL·SIGTERM 중 이중 반영 없음, DB 재시작·kill -9 후 복구와 `/readyz`, 같은 Idempotency-Key 재전송·동시 전송, 틀린 Host/Origin/Sec-Fetch-Site/CSRF 가 막히는 계층(nginx 444 ↔ 백엔드 403), 속도 제한 2계층, 요청 크기 2계층, 백업→복원(복원 후 `audit_log` 권한·체인), 마이그레이션 0001→0002(새 DB·기존 DB), 시간 경과는 DB `scheduled_date`·`applied_at` 직접 조정(명시)
  3. **인프라 실가동**: 컨테이너 보안 설정 실측, DEC-045 네트워크 3분리(web→db 도달 불가), 기동 순서, 비밀 비노출, TC-VI-055·106 xfail 재평가, 운영 PowerShell 스크립트를 pwsh 7.4(Linux)로 실행
  4. **화면 통합**: Chromium(헤드리스 1194)으로 `http://127.0.0.1:18080` 에서 홈 → 영상 목록 → 상세 → 제안 생성 → 승인·수정·반려 → 배치 → 실행 → 이력 → 롤백 → 리포트 → 설정(PIN·감사·로그아웃) 클릭 수준 순회, 콘솔·네트워크·CSP 수집
  5. **6단계 조건부 항목 종결**(6절 아래 표)과 11단계 문서의 코드 후속 조치 C-1~C-10 재현

## 3. 테스트 환경
- 실행 환경: Linux 6.18(클라우드 컨테이너, 루트), Docker Engine 29.8.2 / Compose 5.6.0, Chromium 1194(`/opt/pw-browsers`, Playwright 은 `/opt/node22` 전역 모듈), pwsh 7.4.13, 시험 러너 파이썬 3.13(`.harness-tmp/int/venv_07_f`: httpx·pytest·jsonschema·psycopg·pyyaml·pytest-timeout)
- 스택: `docker compose -p harness-tmp-int`, 이미지 3종 `harness-tmp-int-{api,web,db}:local` 를 최신 코드로 `--no-cache` 빌드(프록시 CA 주입은 저장소 Dockerfile 사본 2줄만 다름, 저장소 Dockerfile 미수정). 호스트 게시 `127.0.0.1:18080` 한 개. 컨테이너: db(PostgreSQL 17)·migrate(종료 코드 0)·api·worker·web 전부 healthy. 이미지 파이썬은 3.12 → **6단계 미수행이던 Python 3.12·PostgreSQL 17·nginx 경유가 이번에 실측됨**
- 포트 18080 일치 방법(저장소 파일 미수정): 호스트 게시 포트 한 줄 + `YTWEB_ALLOWED_HOSTS`(백엔드, 18080·8080 모두 허용) + nginx 허용 Host 맵에 `127.0.0.1:18080`·`localhost:18080` 추가한 읽기 전용 `nginx.conf` 사본 마운트. 시험 대부분은 `Host/Origin: 127.0.0.1:8080` 헤더로 보냈고(운영 기본값 고정 설계), 화면은 실제 주소 `127.0.0.1:18080` 으로 접속
- 보조 트랙(네이티브): 도커 없이 임시 PostgreSQL 16(포트 54341, `.harness-tmp/int_b`) + uvicorn api + 워커(속도 제한 완화). Docker 스택에서 건너뛴 10건(프로세스·DB 직접 제어 6건, 제한 해제 서버 필요 2건, 전체 세션 판정 2건) 전부를 이 트랙에서 수행했다(IT-421 은 시험 파서 문제로 비고). **참고: 할당받은 `ytweb_test_f`(127.0.0.1:54329)는 이번 시험에서 사용하지 않았다**(스택의 DB 는 컨테이너 안 PostgreSQL 17, 보조 트랙은 별도 인스턴스). 따라서 해당 DB 에 만든 객체는 없다
- 테스트 데이터: 데모 모드 영상 200개(제외 37개), 모의 제안기(결정적 템플릿), 시험마다 `reset-demo` 와 같은 순서(web/api/worker 정지 → 스키마 초기화 → 기동)로 빈 DB 에서 시작
- 전제 조건: 6단계 4개 단위 결과서 존재(BE-A PASS, BE-B PASS, FE·INF 조건부 PASS). 비밀 파일은 `.harness-tmp/int/secrets`(값은 어디에도 출력하지 않음)
- 시험 코드(재사용·보완): 기존 `web/tests_integration/`(01~05, 이전 세션 작성) 재사용. 이번에 **보완·추가**: `test_it_06_screen_claims.py`(C-1~C-9 서버 쪽 사실 확인 6건) 신규, `test_it_04_contract.py`에 IT-436·IT-437(신규 결함 고정 2건)과 IT-432·IT-433 의 기대 수정, `test_it_05_ops.py` 의 IT-505·IT-530 하네스 오류 수정, `web/tests_infra/test_vi_independent.py` 의 TC-VI-103 에 낡은 시험 표시(마커). 제품 소스는 수정하지 않았다
- 실행 방법 요약: `IT_STACK_DIR=<스택 폴더> DOCKER_HOST=unix:///var/run/docker.sock IT_PWSH=<pwsh> python -m pytest web/tests_integration -p no:cacheprovider -q -rxXfsE --timeout=1500`, 화면은 임시 Playwright 스크립트(정리로 삭제)
