## 5. 설계 대비 확인한 보안 항목

잠금(5회→5분→10분, 최대 1시간)·잠금 중 맞는 비밀번호 거부(TC-AL-006), 동시 20개 추측이 4번만 검증되고 나머지 잠금(TC-AL-102, 실제 PostgreSQL), 아이디·비밀번호 오류 동일 응답(TC-AL-005), 해시만 저장(TC-AL-014), 감사 기록에 값 없음(TC-AL-013), 익명 세션 차단(TC-AL-002), 로그인 전 보호 API 401(TC-AL-003), 60분 무활동 만료(TC-AL-008), 새 로그인 시 이전 세션 종료(TC-AL-009), 비밀 파일 없으면 로그인 불가(TC-AL-016).

## 6. 남은 위험·미확인

- Windows 실기·브라우저·실제 스택 확인 전이다. 첫 사용 시 `start.ps1` 이 아이디·비밀번호를 물으므로 선생님 PC에서 한 번 확인이 필요하다.
- 관리자 1명이라 잠금이 계정 전체에 걸린다(최대 1시간, 같은 PC 한정). 비밀번호 원문이 `web\secrets` 파일에 남는다(PC 1인 전용 전제).
- `restore.ps1`·`reset-demo.ps1` 은 비밀 파일이 없으면 시작이 실패하므로 `start.ps1` 을 먼저 실행해야 한다.
