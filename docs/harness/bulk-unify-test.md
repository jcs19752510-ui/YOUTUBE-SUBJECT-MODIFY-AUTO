## 3. 결함 (고치지 않음, 구현자에게 전달)

- **DEF-BU-001 (Medium)** videos API 실패 시 오류 안내·재시도 없음. 재현: 모의 `GET /api/v1/videos` 가 500 → 진행 상태에서 '제안 있음(검토 대기)' 선택. 결과: 화면은 깨지지 않지만(크래시 없음) 목록이 비고 "맞는 제안이 없습니다"만 나와, 실패인데 "해당 제안 없음"으로 오인한다. 원인: `BulkApprovePage.tsx` 의 `statusVideos` 의 isError 를 사용하지 않음(97행 부근). 기대: 영상 목록 로딩 실패 안내+다시 시도.
- **DEF-BU-002 (Low~Medium)** videos API 응답 대기 중 "맞는 제안이 없습니다"와 "승인 가능한 제안 0건"이 거짓으로 표시. 재현: videos 응답을 지연시키고 진행 상태 선택. 원인: `statusVideos.isPending` 을 판단하지 않고 빈 집합으로 거름. 기대: 로딩 표시(Skeleton/"불러오는 중").
- **DEF-BU-003 (Medium)** 해당 상태 영상이 200개를 넘으면 201번째부터의 영상 제안이 가려짐. 재현: videos 모의가 total=250 을 쪽 나눠 응답 → 진행 상태 선택 → 캡션이 "250건"이어야 하나 "200건". 원인: `api.videos({status, page_size:200})` 1쪽만 사용(page 반복 없음). 영상 200개 채널이라 지금은 영향이 적으나 영상 수가 늘면 조용히 누락(누락 안내도 없음).
