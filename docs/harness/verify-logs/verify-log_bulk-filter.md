## 2. 범위
- 포함: 목록 줄이기 3종 동작, 줄인 뒤 [현재 목록 전체 선택]·[선택 해제]가 보이는 항목에만 작용하는지, 숨긴 항목의 선택 유지, 50건 상한, 입력 안전·접근성, 방법 B 무영향.
- 제외(미수행): 변이 점검(이 기능 대상), Chromium 화면 캡처, 선생님 PC 실제 화면 확인, 실제 서버(API) 연동 시험.
