# 쇼츠 AI 제안이 안 보이는 문제 — 원인 분석·조치 (2026-10-14)
증상: 쇼츠 영상 [선택 영상 AI 제안 생성]이 "1/1 처리됨 · 완료"인데 영상 목록·일괄 승인에 제안이 없음.
원인(재현 시험, 저장 안 함): 조회 조건이 아니라 제안이 만들어지지 않음. AI 키가 없어 규칙 기반 제안기(`ai/rule.py`)가 쓰이고, 이 제안기는 영상 설명의 챕터 시간표("0:30 제목")로만 후보를 만든다. 60초·챕터 없음 → ai_no_candidates, 200초·챕터 없음 → ai_no_candidates, 60초·챕터 3줄 → 후보 2개. 쇼츠여서가 아니라 챕터가 없어서. 작업은 영상별 실패를 건너뛰고 "완료"만 표시해 이유가 안 보였음(제품 결함).
조치(표시): 작업 결과에 건너뛴 영상 ID·한국어 이유(`reason`), 제안 생성 창에 "AI 제안 N건을 만들었습니다 / 만들지 못한 영상과 이유". 시험 TC-FE-JOB-001~003, 서버 신규 1개, 기존 2개 시험(test_tick, test_vb_07)은 건너뛴 항목 정확 비교라 첫 실행에서 실패 → reason 필드 추가로 기대값 확장.
미조치(선생님 결정 대기): 챕터 없는 영상의 제안은 AI 서비스(Q-1) 연결이 근본 해결. 임시로 제목만으로 후보를 만드는 규칙은 넣지 않음.

## 2차 확인 (선생님 PC 화면, 같은 날)
화면에 나온 실제 이유: `ai_no_candidates` — "AI 응답에서 쓸 수 있는 후보가 없었습니다". → 선생님 PC에서 규칙 기반 제안기가 쓰였고(Gemini 키 파일 `web\secrets\gemini_api_key` 없음/비어 있음) 챕터 없는 쇼츠라 후보 0개. (이 환경에는 키가 없어 Gemini 실호출 시험은 미수행.)
조치: ①규칙 기반 제안기가 후보를 못 만들면 이유를 "AI(Gemini)가 연결되어 있지 않아…"로, 방법을 `web\scripts\gemini-on.bat`로 안내(`suggestions.py`) ②`web/scripts/gemini-on.ps1/.bat` 추가: 키를 보이지 않게 입력받아 `web\secrets\gemini_api_key`(저장소 제외 폴더)에 저장하고 start.ps1 재시작. Windows 실행 미수행.
시험: test_live_suggest 신규 1개 포함 관련 서버 시험 모두 통과(test_live_suggest·test_suggestions·verify_wb 01/07·test_routers·test_tick). 취소한 시도: 제목 구절을 순서만 바꿔 잇는 임시 규칙(어색한 제목·검증 차단 1건) → 되돌림. 취소한 시도 2: 해시태그뿐인 설명에서 제목을 검증 근거에 포함(가설 단계, 실제 원인과 달라 반영 안 함).

## 3차: 쇼츠도 긴 영상과 같은 흐름으로 (선생님 지시)
흐름(생성→검증→승인→배치)은 원래 같았고, 다른 것은 입력(챕터 유무)뿐이었다. 챕터·설명 내용이 없는 영상은 `ai/rule.py`가 현재 제목(설명이 있으면 설명)의 구절을 원래 순서대로 일부만 남긴 짧은 제목을 후보로 만든다. 어색한 재배열은 하지 않음(앞서 취소한 시도: 순서 바꿔 잇기 → 비문·검증 차단).
예(시험 입력은 가짜 ID): `[시니어 필독2]삼성폰 주인도 놀란 기적의 AI! 길 가다 모르는 건 …서클서치` → `[시니어 필독2] 길 가다 모르는 건 동그라미만 치면 다 알려주는 서클서치`(41자, 검증 통과). 후보 수·품질은 제한적(구절을 덜어낼 뿐이라 새 표현은 없음). 좋은 새 제목은 Gemini 연결(gemini-on.bat)이 필요.
시험: test_rule_suggester 7개(신규 2) + `tests/domain`·`tests/verify_wb`·test_gemini_suggester 전체 통과(첫 실행부터 통과, 이 3차 변경 후). 미수행: 선생님 PC 확인, Gemini 실호출.

## 4차: 특정 영상(IC_… 계열, "속도 3배 빨라지는 법/느려진 폰 1분 청소 설정")만 계속 "검증을 통과하지 못해 저장하지 않았습니다"
확인한 사실: 같은 영상의 기존 제안 3개가 모두 "경고 85점"이었고(선생님 화면 2건), 2026-10-13 선생님 요청("경고·차단 후보는 만들지 않는다")으로 통과(pass) 후보만 저장한다. 규칙 제안기는 같은 입력이면 같은 후보를 내므로 이 영상은 다시 눌러도 같은 결과(결정적). 다른 영상은 설명 내용으로 만든 후보가 통과해서 정상.
확인하지 못한 것: 어떤 경고인지(영상 설명 원문·저장된 경고 이유는 선생님 PC DB에만 있음). 내가 가정한 비슷한 설명으로는 같은 제목이 통과함 → 실제 설명에 따라 경고(일치율·근거·핵심어 위치 중 하나)가 난 것으로 추정.
조치: 통과 후보가 없을 때 경고 이유(중복 제거 최대 3개)를 `detail`에 넣고, 규칙 제안기면 Gemini 연결 안내, 아니면 "다시 눌러 새 후보" 안내(`suggestions.py`). 시험 test_pass_only_reasons 1개 신규, tests/domain·verify_wb·test_rule_suggester 전체 통과(첫 실행 통과). 미수행: 선생님 PC 확인.
