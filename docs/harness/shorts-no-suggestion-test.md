# 쇼츠 AI 제안이 안 보이는 문제 — 원인 분석·조치 (2026-10-14)
증상: 쇼츠 영상 [선택 영상 AI 제안 생성]이 "1/1 처리됨 · 완료"인데 영상 목록·일괄 승인에 제안이 없음.
원인(재현 시험, 저장 안 함): 조회 조건이 아니라 제안이 만들어지지 않음. AI 키가 없어 규칙 기반 제안기(`ai/rule.py`)가 쓰이고, 이 제안기는 영상 설명의 챕터 시간표("0:30 제목")로만 후보를 만든다. 60초·챕터 없음 → ai_no_candidates, 200초·챕터 없음 → ai_no_candidates, 60초·챕터 3줄 → 후보 2개. 쇼츠여서가 아니라 챕터가 없어서. 작업은 영상별 실패를 건너뛰고 "완료"만 표시해 이유가 안 보였음(제품 결함).
조치(표시): 작업 결과에 건너뛴 영상 ID·한국어 이유(`reason`), 제안 생성 창에 "AI 제안 N건을 만들었습니다 / 만들지 못한 영상과 이유". 시험 TC-FE-JOB-001~003, 서버 신규 1개, 기존 2개 시험(test_tick, test_vb_07)은 건너뛴 항목 정확 비교라 첫 실행에서 실패 → reason 필드 추가로 기대값 확장.
미조치(선생님 결정 대기): 챕터 없는 영상의 제안은 AI 서비스(Q-1) 연결이 근본 해결. 임시로 제목만으로 후보를 만드는 규칙은 넣지 않음.
