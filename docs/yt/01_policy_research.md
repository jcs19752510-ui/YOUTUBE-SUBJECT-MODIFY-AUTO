# YT-01 사실 확인 및 정책 조사 (하네스 1단계 산출물)

- 조사 일자: 2026-10-10 (모든 "확인 일자"는 이 날짜)
- 작성: 오케스트레이터(1단계 역할 직접 수행, DEC-011)
- 적용 법규 기준: **대한민국**(사용자 무응답으로 기본값 적용, DEC-005) + YouTube/Google 약관
- 업무 유형: 신규 개발, Tier: Standard (DEC-001, DEC-004)

## 0. 읽기 전에: 이 조사의 한계 (중요)
`developers.google.com`과 `support.google.com`이 이 클라우드 환경의 네트워크 정책으로 차단돼 있어(DEC-010) **공식 원문을 직접 열람하지 못했다.** 웹 검색이 돌려준 공식 URL의 검색 요약과 제3자 자료만 근거로 썼다. 따라서 v1 표기 규칙에 따라 **어떤 항목도 `[확인됨]`으로 표기하지 않았다.** 근거 등급은 다음과 같다.

| 등급 | 뜻 |
|---|---|
| **A** | 공식 URL이 검색에 나왔고, 검색 요약이 그 공식 내용을 직접 인용·요약함 (원문은 미열람) |
| **B** | 기사·블로그·경쟁 제품 페이지 등 제3자 자료만 있음 |
| **C** | 근거를 찾지 못함 |

**권고(사용자 조치)**: 환경의 네트워크 설정에서 위 두 도메인을 허용하면 이 문서의 A·B·C 항목을 원문으로 재확인할 수 있다(방법: 세션 제목 줄의 클라우드 환경 메뉴 → Edit → Network access → Allowed domains에 추가, 안내: https://code.claude.com/docs/en/cloud-environments#network-access). 재확인 결과가 다르면 규칙 F로 02단계부터 영향 범위를 다시 산정한다.

### b. 공식 A/B 테스트를 API로 시작·조회할 수 있는가
- 이번 검색에서 **API로 A/B 테스트를 시작하거나 결과를 읽는 방법을 찾지 못했다.** 그러나 "없다"를 증명한 것이 아니다. → **[확인 필요]**, 등급 C.
- **결정(v1 지시)**: 불가한 것으로 보고 구조를 고정한다 — "공식 테스트는 Studio에서 사람이 실행. 프로그램은 제목 후보 검증, Analytics 지표 수집, 확정 제목 반영, 이력/롤백만 담당." 나중에 API 지원이 확인되면 규칙 F로 재설계한다.

**규칙 I 판정(DEC-012)**: 프로그램 자체는 조언을 하지 않으므로 직접 해당하지는 않으나, 대상 채널이 건강·금융 주제를 다루므로 **보수적으로 적용**한다. 2단계에서 관련 대응을 `POL-xxx`/`SEC-xxx`로 등록한다. **실제 법률 자문을 받을 것을 권고한다**(에이전트가 이를 대신할 수 없다).

- **쿼터 초기화 시각**: 태평양 시간 자정(A). 한국 시간으로는 서머타임 여부에 따라 오후 4~5시 무렵이다 → "하루" 경계를 PT 기준으로 계산해야 한다.

### 3-6. 규칙 J(AI/LLM) 확인
프로그램은 LLM API를 호출하지 않는다(DEC-003). 후보 제목은 사용자가 별도로(예: Claude 대화) 만들어 `candidates/{video_id}.json`으로 입력한다. 따라서 **프로그램 내부의 프롬프트 인젝션 경로는 없다.** 단, 후보 JSON은 외부에서 만든 신뢰할 수 없는 입력으로 취급한다(SEC로 등록). 만약 LLM 호출을 추가하면 규칙 J와 Tier를 재평가한다(재평가 트리거). AI 관련 국내 법령(AI 기본법 등)의 적용 여부는 **[확인 필요]**이며, AI가 만든 제목을 사용자가 채택해 게시하는 행위의 고지 의무 여부도 확인하지 못했다.

## 4. 리스크 및 불확실성 (숨기지 않고 명시)
1. 공식 원문 미열람(DEC-010) — 2장 전 항목이 영향을 받는다.

## 5. 2단계(기획서)에 특히 반영할 시사점 (5개)
1. **공식 A/B와 분리된 설계**: API 근거가 없으므로 Studio A/B는 사람이 실행하고, 프로그램은 검증·반영·이력·롤백만 한다. 순차 교체 모드는 기본 비활성이며 비교 신뢰도 한계를 명시한다.
2. **쿼터는 여유가 있으나 설정값으로 통제**: 하루 10,000 units 중 60% 이하 상한을 기본값으로 하고, `videos.update` 비용(가정 50)은 설정값으로 둔다. 하루 경계는 태평양 시간 기준.
3. **OAuth 운영 방식은 사용자 결정**: 테스트 모드의 7일 만료 vs 운영 전환 비용을 선택지로 제시한다. 토큰 만료·재인증 처리는 필수 요구사항.
4. **제목 검증기에 규격과 규제 표현을 반영**: 100자·`<` `>` 규격, 건강·금융·사칭 표현 차단, 시니어 대상 공포 조장 차단, 건강·금융 엄격 모드. 규칙 I을 보수적으로 적용해 `POL-xxx`로 등록.
5. **지표 수집 대안 경로**: Analytics API로 노출·CTR을 못 받으면 Studio CSV 가져오기를 대안 FR로 둔다. 변경 전후 비교는 순차 비교의 한계를 항상 병기한다.
