## 6. 내 컴퓨터 준비 (PowerShell)
### 6-1. 파이썬 확인
```powershell
py -3.12 --version
```
`Python 3.12.x`가 나오면 통과입니다. `py`를 찾을 수 없다는 오류가 나면 `python --version`을 시도해 3.12인지 확인하고(이 경우 이후 `py -3.12` 대신 `python`을 쓰세요), 없으면 파이썬 공식 사이트(`python.org`)에서 3.12를 설치하세요(설치할 때 "Add python.exe to PATH" 체크). 설치 명령(`winget install Python.Python.3.12`)은 환경에 따라 다를 수 있습니다 [확인 필요].

### 6-2. 가상환경(venv) 만들기와 켜기
가상환경은 "이 프로젝트 전용 파이썬 상자"입니다. 다른 프로그램과 섞이지 않게 해 줍니다.
```powershell
cd C:\big21\vibe-coding\YOUTUBE-SUBJECT-MODIFY-AUTO
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```
성공하면 줄 맨 앞에 `(.venv)`가 붙습니다. 이후 명령은 이 상태에서 실행합니다. 새 PowerShell 창을 열면 위의 `Activate.ps1` 줄을 다시 실행해야 합니다.

### 6-3. "스크립트를 실행할 수 없습니다" 오류가 나올 때 (실행 정책)
`Activate.ps1`에서 빨간 글씨로 *이 시스템에서 스크립트를 실행할 수 없으므로*라고 나오면, **현재 창에서만** 허용합니다(가장 안전).
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
```
창을 닫으면 원래대로 돌아갑니다. 계속 불편하면 사용자 전체에 적용하는 방법도 있지만(`-Scope CurrentUser`), 보안상 위 방법을 먼저 권합니다. 그래도 안 되면 PowerShell 대신 명령 프롬프트(cmd)에서 `.\.venv\Scripts\activate.bat`을 실행하세요.

## 7. 비밀 파일이 깃허브에 올라가지 않게 하기
### 7-1. `.gitignore`에 아래 줄이 들어 있어야 합니다
`.gitignore` 파일을 메모장으로 엽니다(`notepad .gitignore`, "새 파일을 만들까요?"가 나오면 이미 있는 파일이므로 보통 나오지 않습니다). **없으면 맨 아래에 추가**하세요. 탐색기에서 안 보이면 숨김 파일 표시를 켜세요. (하네스가 이미 `.harness-tmp/`, `*.sqlite3` 등은 넣어 두었습니다.)
```
# 비밀·개인 데이터 (YT-03)
.env
secrets/
token*.json
*.token
data/
config/settings.local.yaml
approvals/
```
- `data/`는 프로그램이 만드는 DB와 백업이 들어갈 폴더로 예약합니다(3단계 설계서에서 확정).
- `candidates/` 폴더는 제목 후보 파일입니다. 비밀은 아니므로 올려도 되지만, 올리고 싶지 않으면 한 줄 추가하세요.

### 7-2. `.env` 파일 만들기
프로젝트 루트에서 `notepad .env`를 실행해 새 파일을 만들고(만들까요? → 예) 아래처럼 씁니다. 저장할 때 파일 형식이 "모든 파일"이고 이름이 `.env.txt`가 되지 않았는지 확인하세요(값은 3단계 설계서에서 확정되며, 지금은 예약만 합니다).
```
# YouTube 제목 도구 설정 (이 파일은 절대 공유하지 마세요)
YT_CLIENT_SECRET_PATH=secrets\client_secret.json
YT_TOKEN_DIR=%LOCALAPPDATA%\youtube-title\tokens
YT_DATA_DIR=data
```
- 로그인 토큰은 프로젝트 폴더가 아니라 **내 사용자 폴더**(`YT_TOKEN_DIR`)에 저장됩니다. 실수로 깃허브에 올라갈 일이 없게 하기 위함입니다.
- 사용량 상한·실제 수정 허용 같은 **정책 값은 `.env`가 아니라 `config/settings.yaml`과 `config/settings.local.yaml`**에 둡니다(설계서 5-3). `enable_live`(실제 수정 허용)와 `live_allowlist`(수정을 허용할 영상 ID 목록)는 `settings.local.yaml`에서만 인식되며 기본은 꺼짐·빈 목록입니다. 두 조건에 더해 승인 파일과 명령 옵션(`--live`)도 맞아야만 실제 수정이 가능합니다.

### 7-3. 비밀이 올라가지 않았는지 확인 (git을 쓰는 경우, 사용자가 직접)
```powershell
git status
```
`.env`, `secrets\`, `token...` 파일이 목록에 **보이면 안 됩니다**. 보이면 커밋하지 말고 알려 주세요.

## 8. 첫 인증은 나중에 합니다
`client_secret.json`을 저장해 두면 이 가이드의 준비는 끝입니다. 실제 로그인(인증)은 **WU-1(OAuth 모듈)을 만든 뒤** 아래처럼 합니다. 지금은 실행하지 마세요(프로그램이 아직 없습니다).
```powershell
# (WU-1 완료 후 안내 예정) 읽기 권한 인증
python -m youtube_title auth --read
```
브라우저 창이 열리면 채널 소유 계정으로 로그인하고 "허용"을 누릅니다. "확인되지 않은 앱" 경고가 나오면 본인이 만든 앱이므로 **고급 → 계속**으로 진행할 수 있습니다 [확인 필요].

## 9. 자주 생기는 문제
| 증상 | 원인 | 해결 |
|---|---|---|
| 7일 뒤 "인증 만료"가 나옴 | 테스트 상태의 정상 동작 | `auth --read`를 다시 실행(4-1 참고) |
| "access blocked / 앱이 확인되지 않음" | 테스트 사용자에 본인이 없음 | 동의 화면의 테스트 사용자에 본인 계정 추가 |

| "quotaExceeded" | 하루 사용량 초과 | 다음 날(태평양 시간 자정 이후) 다시 시도. 한국 시간 오후 4~5시쯤 초기화 [확인 필요] |

| 한글이 깨져 보임 | 터미널 인코딩 | PowerShell에서 `chcp 65001` 실행 후 재시도 [확인 필요] |
