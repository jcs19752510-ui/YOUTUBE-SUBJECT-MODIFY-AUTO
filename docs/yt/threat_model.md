## 4. LLM/AI 기능 추가 위협 (규칙 J)
**해당 없음 — 사유**: 프로그램이 LLM을 호출하지 않는다(DEC-003, ADR-007). 후보 제목은 프로그램 밖에서 만들어 파일로 입력된다. 입력 경로의 위험은 T-02, T-13, 후보 내용 검증(FR-002)이 다룬다. LLM 호출을 추가하면 이 절과 Tier를 재평가한다(재평가 트리거).
