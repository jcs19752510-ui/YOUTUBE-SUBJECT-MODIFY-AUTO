# 04 UX 설계서 — CLI 사용 경험 (하네스 4단계)

- 입력: `02_planning.md`(v4), `DESIGN.md`(v0)
- 이 프로그램은 **화면 UI가 없는 CLI**다. 하네스의 "화면(`SCR-xxx`)"은 **터미널 출력 한 덩어리**로 읽는다. 사용자는 초보 개발자 1인, 환경은 Windows + PowerShell이다.
- 원칙: ①쉬운 한국어 ②색에만 의존하지 않기 ③위험한 동작은 한 번 더 확인 ④오류는 "무엇이/왜/다음에 할 일" 순서 ⑤법률 자문 아님 문구(POL-002)

## 2. 화면(터미널 출력) 명세 (`SCR-xxx`)
공통 요소: 맨 위 한 줄 **제목 줄**(`[명령] 모드: 모의 실행(dry-run)` 또는 `모드: ★실제 적용(LIVE)★`), 맨 아래 한 줄 **면책 문구**(POL-002). 상태는 항상 **기호+글자**로 표시한다: `[통과]` `[경고]` `[차단]` `[주의]` `[완료]` `[실패]`.

| ID | 화면 | 목적 | 구성 요소 | 정상/빈/오류/진행 상태 |
|---|---|---|---|---|
| SCR-001 | 메인 도움말 (`--help`) | 무엇을 할 수 있는지 한눈에 | 등록된 명령(완성 시 9개) + 한 줄 설명 + "처음이면 03 가이드부터" 안내 + 기본이 모의 실행임을 명시 | 정상만 |
| SCR-002 | 검증 리포트 | 후보별 통과/경고/차단과 이유 | 영상 ID·현재 제목, 후보 표(번호, 제목, 글자 수, 결과, 사유), 사용한 금칙어 사전 버전(해시 앞 8자, SEC-017), 일치율과 "설명 미사용" 표기, 건강·금융 엄격 모드 표시 | 정상(전부 통과), 경고/차단 있음, **빈 상태**(후보 0개: "후보 파일에 후보가 없습니다. 형식은 …"), 오류(파일 형식 오류: 어느 필드가 왜) |
| SCR-003 | 계획(dry-run) diff | 무엇이 어떻게 바뀌는지 | 변경 전/후 제목을 나란히, **바뀌지 않는 항목 목록**(설명·태그·카테고리 "그대로 유지"), 계획 해시, 안내 "공식 A/B 테스트 중인 영상이 아닌지 Studio에서 확인하세요"(RISK-011), 쿼터 예상 사용량 | 정상, 교체 제한 위반(사유와 가능한 시각), 쿼터 부족, 영상이 목록에 없음(`fetch` 안내) |
| SCR-004 | 승인 완료 | 승인 파일 생성 확인 | 승인자, 대상 영상·새 제목, **만료 시각**, 파일 경로, 다음 명령 안내 | 정상, 이미 승인 존재(덮어쓸지 확인), 계획 해시 불일치 |
| SCR-005 | 적용 전 요약·확인 | 마지막 사람 확인 | `★실제 적용(LIVE)★` 경고, 영상 ID·제목, 변경 전/후, 조건 체크 표(플래그/설정/허용 목록/승인/제한/쿼터/현재 제목 일치), **"계속하려면 영상 ID를 그대로 입력하세요"** | 모든 조건 `[통과]`일 때만 입력 단계로. 하나라도 `[차단]`이면 이유와 해결 방법 출력 후 종료(코드 3) |
| SCR-006 | 적용·롤백 결과 | 결과와 사후 검증 | 진행 표시(① 백업 ② 호출 ③ 재조회 검증), 최종 `[완료]/[실패]`, 제목 반영·설명·태그·카테고리 보존 검증 결과, 변경 번호, 롤백 명령 예시 | 성공, **검증 실패(큰 경고 + 롤백 명령 안내)**, 호출 실패(재시도 횟수 표시) |
| SCR-007 | 조회 요약 (`fetch`) | 가져온 내용 확인 | 영상 수, 공개/비공개/아동용 개수, 쿼터 사용량(오늘 사용/상한), 지표 수집 성공 여부 | 정상, 영상 0개, 인증 만료(SCR-009 연결), API 지표 불가(CSV 안내) |
| SCR-008 | 성과 리포트 | 변경 전후 비교 | 영상 제목 변경 이력, 전/후 노출·클릭률·시청 시간 표, **"순차 비교는 다른 요인(시기·노출 차이)의 영향을 받아 원인을 단정할 수 없습니다" 한계 문구 상시 출력**(FR-018), 기준선 스냅샷 없음 표시 | 정상, 후 지표 부족(수집 예정 날짜), 기준선 없음(신뢰도 낮음 경고) |
| SCR-009 | 오류 안내 | 막혔을 때 다음 행동 | 형식: `[오류 코드] 무슨 일이 생겼나요` / `왜 그런가요` / `다음에 할 일: <복사해서 실행할 명령>` | 인증 만료, 쿼터 초과(초기화 시각 안내), 네트워크 오류(재시도 소진), 설정 오류, 안전 게이트 중단 |
| SCR-010 | 데이터 정리 확인 (`purge`) | 삭제 전 확인 | 삭제 대상 건수·기간, 자동 DB 사본 경로, 보존되는 최근 변경 목록, 확인 입력 | 정상, 대상 0건, 최근 변경 보호 경고 |

### 2-1. 출력 예시 (SCR-002, 형식 기준)
```
[validate] 모드: 모의 실행(dry-run)
영상: abc123DEF45  현재 제목: 겨울철 전기요금 줄이는 방법
주제: 생활  금칙어 사전: v3 (해시 9f2a1c4e)  영상 설명: 사용함

 번호  글자수  결과    제목                                   사유
  1     21    [통과]  전기요금 줄이는 난방 습관 5가지         -
  2     24    [경고]  이거 모르면 큰일! 겨울 전기요금 폭탄   느낌표 1개, 공포 조장 의심(지침 확인 필요)
  3     18    [차단]  전기요금 100% 무조건 절약               근거 없는 100% 단정

이 검증은 법률 자문이 아니며 최종 책임은 채널 소유자에게 있습니다.
```

## 3. 디자인 시스템 원칙 (터미널용 최소 토큰)
| 토큰 | 값 | 이유 |
|---|---|---|
| 폭 | 80열 기준, 넘으면 줄바꿈(표는 열 축소) | 기본 콘솔 폭 |
| 한글 폭 | 한글·전각 문자는 2칸으로 계산해 표 정렬 | 정렬 깨짐 방지 |
| 상태 표기 | `[통과]` `[경고]` `[차단]` `[주의]` `[완료]` `[실패]` — 기호와 글자 병기 | 색만으로 구분하지 않음 |
| 색 | 기본은 **끔**(`--color`로 켬). 켜도 위 글자는 유지 | 접근성, 복사·붙여넣기 |
| LIVE 표시 | 제목 줄에 `★실제 적용(LIVE)★`, 모의 실행은 `모의 실행(dry-run)` | 실수 방지 |
| 어조 | 존댓말, 짧은 문장, 전문 용어는 괄호로 풀이 | 초보자 |
| 확인 입력 | 쓰기 전에는 `y/n`이 아니라 **영상 ID 직접 입력** | 습관적 Enter 방지 |

- **다국어(i18n)**: 해당 없음(사유: 사용자 1인, 한국어 전용). 날짜는 `YYYY-MM-DD HH:MM`(한국 시간), 쿼터 날짜는 "태평양 시간 기준"을 병기.

| 표 | 한글 폭 정렬, 긴 셀 줄바꿈 |

## 5. 접근성 기준 (CLI)
- 웹 접근성(WCAG/KWCAG)은 **화면 UI가 없어 직접 적용 대상이 아니다** — 단 한국 관할의 장애인차별금지법상 접근성 의무가 개인 CLI 도구에 적용되는지는 **[확인 필요]**(개인용이라 가능성 낮음).
- 대신 CLI 접근성 기준을 정해 8단계가 점검한다.
| 점검 항목 | 기준 | 연결 |
|---|---|---|
| 색 비의존 | 모든 상태가 글자로도 구분된다(`--color` 꺼도 동일) | UX-002, UX-005 |
| 스크린리더 친화 | `--plain` 옵션: 표 대신 한 줄씩 `항목: 값` 목록으로 출력 | UX-002, UX-003 |
| 키보드만 사용 | 모든 입력은 키보드, 마우스 불필요 | 전체 |
| 큰 글씨 | 글꼴 크기는 터미널 설정 사항임을 RUNBOOK에 안내(확대 방법) | UX-001 |
| 시간 제한 없음 | 확인 입력에 시간 제한 없음(승인 파일 만료만 있음) | UX-005 |
| 오류 가독성 | 오류마다 "다음에 할 일" 포함 | UX-008 |

## 6. 반응형/디바이스 대응 기준 (지원 환경 목록 — 8단계 호환성 테스트 기준)
| 구분 | 지원 | 비고 |
|---|---|---|
| OS | Windows 10, Windows 11 | **주 지원** |
| 셸 | PowerShell 5.1, PowerShell 7 | |
| 터미널 | Windows Terminal, 기본 콘솔 | 한글 폭·UTF-8 확인 |
| Python | 3.12 (3.10+ 호환) | |

### 6-1. 디자인 자산 관리
- 이미지·아이콘·폰트 없음(해당 없음: 텍스트 출력). 토큰은 `ui.py`의 상수로 코드와 1:1 연결. 다크모드: 해당 없음(터미널 테마를 따름).
- **사용성 확인 계획**: 5~8명 과업 테스트는 불가(사용자 1인). 대체: 사용자가 `03_manual_setup.md`와 RUNBOOK을 처음부터 따라 하며 **막힌 지점과 걸린 시간을 기록**하고 이를 8단계 UAT에 반영한다. 한계: 사용자 1인의 경험이라 일반화할 수 없다.
