# YT 프롬프트 ↔ 하네스 충돌·기본값 색인

> 원본(내용 전체)은 `docs/harness/decisions.md`이다(DEC-007: 로그를 두 곳에 나눠 쓰지 않는다). 이 파일은 v1 프롬프트가 요구한 위치에서 **충돌 내용과 처리 방식, "기본값 적용" 내역**을 한눈에 보게 하는 색인이다.

## 1. 프롬프트와 하네스의 충돌 및 처리
| # | 충돌 | 처리 | DEC |
|---|---|---|---|
| 1 | v1이 전제한 `HARNESS_BASIC`·`harness_*.md`가 이 저장소에 없음(실제는 `HANESS_AUTO` 13단계) | `ORCHESTRATOR.md`로 읽음 | DEC-008, DEC-002 |
| 2 | v1 "git 조회까지 전면 금지" vs 하네스 규칙 K의 `git status` 정리 확인 | v1(사용자 지시) 따름. 정리 확인은 파일시스템 점검으로 대체, 결과서에 "git status 미실행" 명시. 현재 `CLAUDE.md`에 git 금지 조항은 없음 | DEC-006 |
| 3 | v1 "멈추는 곳 정확히 2곳" vs 규칙 A(질문 시 멈춤), 규칙 E(승인) | 기본 2곳(설계 승인, 실제 수정 활성화)을 유지하고 규칙 A의 치명적 공백만 모아서 질문 | DEC-009 |
| 4 | v1 산출물 경로 `docs/yt/*` vs 하네스 `docs/harness/*` | v1이 이름 지정한 문서는 `docs/yt/`, 하네스 공통 문서는 `docs/harness/` | DEC-007 |
| 5 | v1 "다시 묻지 마라" vs 규칙 A | YT-00 질문 9개에 사용자가 답하지 않아 기본값 적용 후 진행 | DEC-003 |
| 6 | v1 YT-10(실제 수정)이 YT-11(운영 문서)보다 앞 vs 하네스는 문서화(11) 후 배포(12) | 하네스 순서를 따라 운영 문서를 실제 수정 앞으로 이동(v2 개요서 5장) | DEC-002 |
| 7 | v1 YT-00 질문 7 "공개 정보 조회 시도" vs v1 §5-7 "크롤링 금지" | 크롤링하지 않음. 미제공이면 `fetch`(공식 API)로 대체 | DEC-003 |
