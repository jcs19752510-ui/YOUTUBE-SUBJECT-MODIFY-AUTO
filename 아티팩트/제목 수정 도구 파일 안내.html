제목 수정 도구 파일 안내

이 프로그램(ytitle)은 유튜브 채널 '시니어 생활팁'의 영상 제목을 안전하게 바꾸기 위한 도구입니다. 제목 후보를 검사하고, 사람이 승인한 것만 바꾸고, 바꾼 기록을 남기고, 필요하면 되돌립니다. 아래는 저장소에 있는 파일이 각각 무엇인지 쉬운 말로 풀어 쓴 안내서입니다. 파일 이름이 어렵게 보여도 맨 윗줄(굵은 글씨)만 읽으면 무슨 파일인지 알 수 있게 만들었습니다.

낱말 풀이내부 테스트 결과서프로그램 부품명령어 파일기획·설계 문서진행 관리 문서

먼저, 어려운 낱말 풀이

WU (작업 단위)
프로그램을 7조각(WU-0~6)으로 나눈 개발 단위. 한 조각씩 만들고 한 조각씩 시험했습니다.
단위 테스트
한 조각이 설계대로 동작하는지 자동으로 확인하는 시험. 구글에는 연결하지 않고 가짜 데이터로 합니다.
변이 점검
코드를 일부러 망가뜨려 보고, 시험이 그 고장을 잡아내는지 확인하는 검사. 시험이 허술하면 고장을 놓칩니다. "47/47"은 47번 망가뜨렸고 47번 모두 잡았다는 뜻입니다.
커버리지
시험이 코드의 몇 %를 실제로 실행해 봤는지. 100%면 모든 줄을 지나갔다는 뜻입니다.
모의 실행 (dry-run)
실제로는 아무것도 바꾸지 않고 "이렇게 바뀔 것"만 보여 주는 방식. 이 도구의 기본 동작입니다.
안전 게이트 14단계
실제로 제목을 바꾸기 전에 거치는 14개의 확인 관문. 하나라도 막히면 아무것도 바꾸지 않습니다.
승인 파일
사람이 "이 제목으로 바꿔도 된다"고 도장 찍은 파일. 계획이 조금이라도 달라지면 무효이고, 한 번만 쓸 수 있고, 시간이 지나면 만료됩니다.
롤백
바꾼 제목을 이전 제목으로 되돌리는 것.
쿼터
구글이 하루에 허용하는 사용량. 넘기면 그날은 더 못 씁니다.
추적표
기획서의 요구사항이 설계, 코드, 시험까지 빠짐없이 이어지는지 적어 둔 표.

내부 테스트 결과서 (7개)

위치는 모두 docs/harness/units/ 폴더입니다. 파일 이름의 숫자(unit-0 ~ unit-6)가 작업 단위 번호입니다. 7개 모두 합격(PASS)이고, 같은 번호의 검증 로그(docs/harness/verify-log_unit-N-test.md)가 따로 있습니다.

한계: 실제 구글 서버와 연결하는 부분(실제 제목 변경, 실제 응답 형식)은 이 테스트로 확인하지 못했습니다. 12단계에서 비공개 테스트 영상으로 확인해야 합니다. Windows 전용 동작도 Linux 환경에서는 확인하지 못했습니다.
