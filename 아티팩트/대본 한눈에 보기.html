클로드 코드가 무엇이고, 어떻게 설치해서 코드 탭을 여는지

  • 이 앱에서는 명령어를 치지 않아도 되고, 데스크탑 앱의 코드 탭에서 폴더를 고르고 말로 시킨다
  • 챗 = 물어보기, 코워크 = 목표 맡기기, 코드 = 내 폴더의 파일 만들고 고치기. 오늘은 코드 탭만 쓴다

가게를 준비하면 할 일이 끝이 없죠. 홍보 글 쓰고, 문의에 답장하고, 주문 정리하고, 홈페이지까지 만들어야 합니다. 이걸 혼자 하다 보면 정작 상품을 만들 시간이 모자라요.

클로드 코드는 이런 반복 일을 말로 시키면, 내 컴퓨터 폴더 안에서 파일을 만들고 고쳐 주는 도구입니다. 이 앱에서는 검은 화면에 명령어를 치지 않아도 됩니다. 클로드 데스크탑 앱 안에 코드 탭이 있고, 거기서 폴더를 고르고 말로 시키면 됩니다.

앱에는 비슷해 보이는 기능이 세 개 있습니다. 챗은 물어보고 답을 듣는 곳이에요. 내 폴더 안의 파일을 직접 만들거나 고치지는 않아요. 코워크는 목표를 맡기면 파일과 도구를 써서 알아서 일하고 결과를 가져옵니다. 코드는 내가 고른 폴더 안에서 파일을 직접 만들고 고치는 곳이에요.

오늘은 이 중에 코드 탭 하나만 씁니다. 홍보 글도, 답변 초안도, 홈페이지도 전부 파일이라서 코드 탭에서 한 번에 되거든요. 참고로 계정에 따라 챗과 코워크가 한 화면으로 합쳐져 있을 수 있어요. 화면이 조금 달라도 코드 탭만 찾으시면 됩니다.

준비물은 세 가지예요. 맥이나 윈도우 컴퓨터, 로그인할 이메일, 그리고 유료 요금제. 이번 영상은 컴퓨터 기준입니다. 컴퓨터를 켜 놓고 따라 해 주세요.

여기서 먼저 알아 두실 게 있어요. 챗은 무료 요금제에서도 쓸 수 있지만, 코드와 코워크는 프로 요금제 이상의 유료 요금제가 필요합니다. 요금은 바뀔 수 있으니 금액은 공식 요금 페이지에서 직접 확인하세요.

사업에 쓸 도구니까, 내가 쓸 만큼 도움이 되는지 오늘 영상으로 먼저 판단해 보셔도 좋습니다.

설치는 공식 다운로드 페이지에서만 하세요. 비슷한 이름의 다른 사이트에서 받으면 안 됩니다. 주소가 공식 클로드 주소가 맞는지 꼭 확인하세요.

맥은 맥오에스용 다운로드 버튼을 누르고, 윈도우는 마이크로소프트 스토어나 직접 내려받기로 설치합니다. 설치가 끝나면 앱을 열고 클로드 계정으로 로그인하세요. 그다음 코드 탭을 누릅니다.

막히는 곳이 세 군데 있어요. 코드 탭에서 업그레이드 안내가 뜨면 유료 요금제가 필요하다는 뜻입니다. 온라인으로 로그인하라는 안내가 뜨면, 안내대로 로그인을 마친 뒤 앱을 다시 시작하세요. 윈도우에서 깃이 필요하다고 나올 때만 깃을 설치하면 됩니다. 그 밖에 필요한 건 화면이 안내해 줍니다.

코드 탭이 열렸다면 준비는 끝났습니다. 이제 사장님 가게 일을 시킬 폴더를 하나 만들 차례예요.

시작하기 전에 안전 약속 세 가지부터 할게요. 하나, 처음엔 매뉴얼로 두고 바뀌는 내용을 눈으로 확인하세요. 둘, 일을 시킬 폴더는 전용 폴더 하나만 고르세요. 내 문서 폴더 전체를 주지 마세요. 셋, 비밀번호나 결제 정보, 고객의 실명과 전화번호는 폴더에도 채팅에도 넣지 마세요. 이 세 가지는 최소한의 약속이에요. 안전을 보장하는 건 아니니, 민감한 건 처음부터 넣지 않는 게 좋습니다. 그리고 입력한 내용은 클로드 서비스로 전송된다는 점도 기억해 주세요.

첫 요청은 오 분이면 끝납니다. 먼저 바탕화면에 새 폴더를 하나 만들고 이름을 내사업이라고 지으세요. 설명란에서 받은 상품정보 파일을 그 폴더에 넣습니다. 이 파일이 우리 가게의 상품과 가격, 가게 사정이 적힌 연습용 자료예요. 하루쿠키라는 가짜 쿠키 가게입니다.

코드 탭에서는 대화 하나를 세션이라고 부릅니다. 시작하기 전에 네 가지를 확인하세요. 환경은 로컬, 내 컴퓨터에서 일하게 합니다. 모델은 처음엔 기본으로 두세요. 폴더 선택 버튼을 눌러 방금 만든 내사업 폴더를 고르세요. 그리고 권한 모드는 처음엔 매뉴얼로 두세요. 바뀌는 내용을 하나씩 확인하고 허락하는 모드예요.

이제 말로 시키고 엔터를 누릅니다. 상품정보 파일을 읽고 가게 소개 글을 다섯 줄로 써서 파일로 저장해 달라고 했어요.

클로드가 파일을 만들겠다고 제안하면서, 무엇이 바뀌는지 화면에 보여 줍니다. 내용을 읽고 괜찮으면 어셉트를 누르세요. 허락하기 전에는 내 파일이 바뀌지 않아요. 마음에 안 들면 거절해도 됩니다.

보세요, 가게 소개 파일이 생겼죠? 첫 결과물입니다. 마음에 안 들면 이렇게 말로 고치게 하면 돼요. 더 짧게, 더 따뜻한 말투로 써 줘, 하고요.

화면과 글이 저랑 조금 달라도 걱정하지 마세요. 같은 요청을 해도 결과는 매번 조금씩 달라집니다. 정상이에요. 그리고 요청은 구체적일수록 좋아요. 그냥 소개해 줘 보다는 누구에게, 몇 줄로, 어떤 말투로 쓸지를 같이 말하는 게 훨씬 낫습니다.

한 가지만 더 해 두겠습니다. 클로드엠디라는 이름의 업무 지침서 파일입니다. 매번 우리 가게 규칙을 다시 설명하기 번거롭잖아요. 한 번 적어 두면 클로드가 이 폴더에서 일할 때 참고하는 규칙 파일이 돼요. 가끔 어길 수도 있으니 결과는 꼭 확인하세요. 존댓말, 가격은 상품정보 그대로, 과장 금지, 모르면 질문. 이 네 가지를 적었어요.

낭독 전체 보기 (6문단)

홍보 글을 매주 만들 거라면, 같은 요청을 매주 붙여 넣게 되겠죠. 이럴 때 쓰는 게 스킬입니다. 한 번 가르쳐 두면 한 줄로 부를 수 있어요.

스킬은 파일 하나예요. 맨 위 머리말에 이 스킬을 언제 쓰는지 적고, 아래에 따라야 할 지침과 규칙을 적습니다. 우리가 방금 한 홍보 글 요청을 그대로 옮겨 놓았어요. 폴더 이름이 곧 명령 이름이 됩니다. 폴더를 위클리 포스트라고 지으면 슬래시 위클리 포스트로 부를 수 있어요.

만드는 방법은 두 가지입니다. 코드 탭에서 클로드에게 이 위치에 이 내용으로 파일을 만들어 달라고 하거나, 폴더를 열어 직접 저장하세요. 만든 뒤에는 새 세션을 열고 슬래시를 쳐서 목록에 나오는지 확인합니다.

슬래시를 누르니 내 스킬이 보이죠. 선택하고 이번 주 주제만 말하면 홍보 글 일곱 개가 나옵니다. 매주 긴 요청문을 쓸 필요가 없어요.

스킬은 하나에 일 하나만 담으세요. 홍보 글은 홍보 글 스킬, 문의 답변은 문의 답변 스킬처럼요. 이름은 짧고 기억하기 쉽게 지으면 슬래시를 쳤을 때 찾기 쉽습니다.

마지막으로 하나만요. 내 폴더에 만든 스킬은 코드 탭에서 쓰는 거예요. 코워크 탭은 내 컴퓨터의 스킬 폴더를 읽지 않고, 계정에 켜 둔 스킬을 가져옵니다. 이 차이만 기억해 두세요.
