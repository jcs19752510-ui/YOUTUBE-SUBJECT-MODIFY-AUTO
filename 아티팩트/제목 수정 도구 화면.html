제목 수정 도구 화면 미리보기

채널 '시니어 생활팁'의 영상 제목을 검사하고, 사람이 승인한 뒤에만 바꾸고, 필요하면 되돌리는 명령어 도구(ytitle)입니다. 아래 화면은 지금 만들어진 코드를 가짜 영상 1개로 실행해 얻은 실제 출력입니다.

유튜브에는 한 번도 접속하지 않았습니다. 영상 ID abc123DEF45와 제목, 지표 숫자는 모두 예시입니다. 실제 반영(--live)은 안전 조건 14단계를 모두 통과해야 하며, 이 미리보기에서는 일부러 막힌 화면을 보여 줍니다.

사용 순서

실제 반영 전 안전 조건 14단계

    이 검증은 법률 자문이 아니며 최종 책임은 채널 소유자에게 있습니다. 개발 상태: 입력 검증과 기록 기능은 내부 검증을 마쳤고, 계획·리포트는 구현이 끝나 독립 검증을 기다리며, 승인·실제 반영·실제 되돌리기는 지금 개발 중입니다. 쿼터(1일 10,000 units)와 지표 이름, CTR 단위는 12단계 실제 테스트 전까지 확인이 필요한 가정입니다.
