설계 원칙

  • 분봉 거래량은 체결의 당일 누적 거래량 차이로 만들어, 체결이 빠지거나 중복돼도 합계가 증권사 누적과 어긋나지 않습니다.
  • 틱은 디스크·DB에 저장하지 않습니다(재배포·용량·약관 위험 최소화).
  • 화면을 닫으면 30초 뒤 구독을 해지하고, 끊기면 지수 백오프로 재연결해 구독을 복구합니다.
  • 앱키·접속키는 서버 환경변수에만 있고 화면·로그·응답에 나오지 않습니다.

주기와 시점

  • 공공데이터포털 시세는 영업일 다음 날에 올라옵니다. 금요일 데이터는 월요일에 공개되므로, 주말에 새 거래일이 없는 것이 정상입니다.
  • 배치는 이미 최신이면 API를 호출하지 않고 끝나며, 빠진 거래일은 오래된 날부터 따라잡습니다.
  • PER·PBR은 배치가 시가총액과 DART 재무 원문을 조합해 계산합니다. 원문 수집을 먼저 해야 값이 나옵니다.
  • 금융위원회 공공데이터는 거래일 다음 영업일 13시 이후에 공개됩니다. 현재 배치(14:30 시작)는 이를 약 1~2시간 늦게 반영하므로, 13:10부터 15분 간격으로 재시도하는 방식이 제안돼 있습니다(결정 대기).
  • 화면의 "갱신" 시각은 데이터가 반영된 시각이 아니라 화면을 불러온 시각입니다(오해 소지, 문구 정정 결정 대기).
  • GitHub 보조 배치(14:50·18:50)는 기본 브랜치(main)에 워크플로 파일이 없어 동작하지 않는 상태입니다. PC가 꺼져 있으면 갱신이 멈출 수 있습니다.
  • 실시간 경로는 위 "실시간 개발 설계"를 참고하세요(내 PC 로컬 모드 전용, 개발 중).
  • 일일 배치 스케줄링은 지금은 다루지 않기로 한 보류 항목입니다(2026-10-02 사용자 결정). 위 시각은 현재 구성의 기준값입니다.

네 가지를 모두 통과해야 응답하고, 하나라도 어긋나면 기능이 있다는 사실도 드러내지 않도록 404를 돌려줍니다. 프런트는 설정 스위치와 사설 주소일 때만 호가·체결·분·틱·투자자 UI를 보여주는 보조 방어선입니다.

데이터 지연 배지·기준 안내

"예상보다 1영업일 지연된 데이터입니다"와 기준일·갱신 시각이 헤더 아래에 나옵니다. 로컬 모드에서 호가·체결·분·틱을 보는 동안에는 기준 안내가 "내 증권사 시세(지연·누락 가능)"로 바뀝니다.

로딩 · 빈 값 · 오류

탭마다 "불러오는 중", "아직 없습니다", 오류 문구로 나뉩니다. 값이 없으면 0이 아니라 "–"로 표시합니다. "서버를 깨우는 중" 팝업은 제거했습니다(DEC-076).

고지 문구

상단 배너와 푸터에 투자자문업 미등록·투자 조언 아님이 항상 있고, 로컬 모드 화면에는 시세 외부 제공 금지 안내가 붙습니다.

시세 원값 노출 스위치

운영은 켜짐(PRICE_EXPOSURE_ENABLED=true)입니다. 끄면 차트·일자별 시세 탭이 빠지고 요약 정보만 남습니다.

참고 이미지·선발 기준 대비 현황

참고 폴더의 증권사 앱 화면 11장과 "급등 전 압축주" 선발 기준 10가지를 기준으로 비교했습니다.

기준현재 조건 체크 탭상태비고

③ 60일선 접근60일선 접근(60일선 대비 %, 간격)구현

⑥ 외국인·기관 수급최근 20거래일 외국인+기관 누적 순매수 > 0 또는 ⑪ 기관 3일 연속 순매수로컬 모드외국인이 팔아도 기관이 연속 매수면 충족. 공개 화면은 출처가 없어 안내만
⑦ 개인 주도 제외같은 기간 개인 누적 순매수 ≤ 0. 예외: ⑪ 충족 + 기관 누적 > 개인 누적이면 충족로컬 모드10거래일 미만이면 산정 불가. 근거 문구에 예외 적용 여부 표시
⑧ 실적 개선 가능성최근 사업연도 영업이익 흑자 + 전년 대비 증가구현공개 화면에도 표시. 수집된 종목만
⑨ 호재 이미 반영된 종목 제외급등 이력(최근 20거래일 급등·거래량 급증, 대리 지표)일부뉴스 자체는 제공하지 않음
⑩ 급등 전 위치 종합충족 여부와 수치 근거만 나열구현점수·순위는 의도적으로 없음
⑪ 기관 연속 순매수오늘 포함 3일 이상 연속 순매수. 0·값 없음은 연속 중단로컬 모드⑥의 대안. 리노공업 화면 수치로 시험. 실제 KIS 응답은 장중 확인 항목

운영 배포 (Render 서비스 1개 + Neon DB)

2026-10-06에 웹과 API를 한 컨테이너로 합쳤습니다. 구성 파일은 render.yaml, deploy/unified.Dockerfile, scripts/run_unified.py이고 절차서는 docs/ops/unified-service-guide.md입니다. 이전 2개 서비스 구성은 deploy/render/render.two-services.yaml에 롤백용으로 보관합니다.

대안 보관: 서버 1대 구성 (Oracle VM + Cloudflare R2)

Oracle 가입이 막혀 Render로 먼저 운영을 시작했습니다. 서버 1대 구성의 파일과 절차서(deploy/docker-compose.yml, deploy/Caddyfile, docs/ops/oracle-deploy-guide.md)는 저장소에 남아 있고, 현재 쓰지 않습니다. 서버를 다시 검토하면 임시 PostgreSQL에서 마이그레이션 적용과 계정 권한 분리, 백업·복구, 배포 스크립트 78개 항목은 시험을 마쳤습니다. Docker 이미지 빌드(ARM), 인증서 발급, R2 실제 업로드는 아직 시험하지 못했습니다.

잘못된 코드를 푸시하면 바로 운영에 배포됩니다(상태 점검을 통과하지 못하면 기존 버전 유지). 끄려면 render.yaml의 값을 "off"로 되돌립니다.

운영 현황 (2026-10-06 기준)

일일 배치

마지막 확인 발행일은 2026-10-01입니다. 이후 거래일은 공공데이터포털이 영업일 다음 날 공개하는 대로 따라잡습니다. PC 작업 스케줄러 실행 기록은 PC에서 직접 확인해야 합니다. 스케줄링 재설계는 보류 중입니다.

실적 수집

삼성전자에서 2023~2025 연결 실적이 표시됩니다. 조건 체크의 실적 점검도 이 데이터를 씁니다.

PER·PBR 원천 재무

수집 전인 종목은 "산정 불가"로 보입니다. 수집 후 가공을 다시 돌리면 값이 채워지고, 비는 종목은 "적자·자본잠식"과 "재무 데이터 없음"으로 나뉘어 표시됩니다. DB 마이그레이션은 0018(인증 역할·가입·관리 기록)까지 적용돼 있습니다.

메모리·콜드스타트

Starter 전환으로 유휴 잠들기와 콜드스타트가 사라졌습니다. 로그인의 재시도(DEC-077)는 Neon DB 자동 정지 대비로 유지합니다.

장중 확인 항목

분봉·투자자 당일 값, 새 기준 ⑪(실제 증권사 응답)은 장중에 PC에서 확인합니다.
