|---|---|---|---|
| `유튜브제목변경-전체진행상황.html` | 유튜브제목변경-전체진행상황 | 13단계 진행률, 시험 결과, 열린 결함, 다음 순서 | 2026-10-13 (커밋 `b7b1cd6` 기준 내용) |

## 보는 방법

1. **내 PC에서 바로 보기**: 파일을 내려받아 브라우저(Chrome·Edge)로 열면 됩니다. 인터넷 연결이 없어도 글은 보이고, 글꼴만 기본 글꼴로 바뀝니다. GitHub 화면에서 `.html`을 열면 소스 코드로 보이므로 내려받아 여세요.
2. **다른 Claude 계정에서 같은 아티팩트로 보기**: 그 계정의 Claude Code에서 이 저장소를 열고 "`아티팩트` 폴더의 HTML 파일을 아티팩트로 발행해 줘"라고 요청하면, 그 계정 소유의 아티팩트로 만들어집니다. 내 계정의 아티팩트 링크(`claude.ai/artifact/...`)는 **비공개**라서 다른 계정은 열 수 없습니다. 같은 링크를 쓰고 싶으면 아티팩트 화면의 **공유(Share)** 메뉴에서 해당 계정을 초대하거나 링크 공유를 켜야 하며, 공유 가능 여부는 플랜·조직 설정에 따라 다릅니다.

## 알아 둘 것

- **이 저장소는 공개(Public)입니다.** 누구나 이 폴더를 읽을 수 있습니다. 그래서 이 사본에서는 구글 클라우드 프로젝트 ID, 예전 시크릿의 끝 4글자, 실제 제목을 바꾼 영상 2개의 ID를 가렸습니다. 비밀번호·키·토큰은 원래 들어 있지 않습니다.
- 이 파일은 **복사본**입니다. claude.ai에서 아티팩트를 고치면 이 파일에 자동 반영되지 않습니다. Claude가 아티팩트를 갱신할 때 이 파일도 같이 갱신합니다(`CLAUDE.md` 규칙).
- 체크리스트(`내할일`)의 체크 표시는 보는 브라우저에만 저장되며 이 파일에는 들어 있지 않습니다.
