## 보는 방법
1. **내 PC에서 바로 보기**: 파일을 내려받아 Chrome·Edge로 엽니다. GitHub 화면에서 `.html`을 열면 소스 코드로 보이므로 내려받아 여세요.
2. **다른 Claude 계정에서 같은 아티팩트로 보기**: 그 계정의 Claude Code에서 이 저장소를 열고 "`아티팩트` 폴더의 HTML 파일을 아티팩트로 발행해 줘"라고 요청하면 그 계정 소유의 아티팩트가 만들어집니다. 내 계정의 아티팩트 링크(`claude.ai/artifact/...`)는 **비공개**라 다른 계정은 열 수 없고, 같은 링크로 보려면 아티팩트 화면의 **공유(Share)** 메뉴에서 선생님이 직접 해당 계정을 초대하거나 링크 공유를 켜야 합니다(플랜·조직에 따라 안 될 수 있음).

## 알아 둘 것 (정확히)
- **이 저장소는 공개(Public)입니다.** 누구나 이 폴더를 읽을 수 있습니다. 선생님이 전부 올리라고 하셔서 올렸고, 올리기 전에 키·토큰·비밀번호 패턴·전화번호·주민번호 패턴을 검사해 **발견 0건**이었습니다(이메일 주소는 예시 `a@b.com` 1건뿐). 단 **내용 전체를 사람이 읽고 검토한 것은 아닙니다.** 이력서·면접·주식 등 다른 사업 정보가 들어 있을 수 있으니 공개해도 되는지 선생님이 한 번 더 판단해 주세요. 이 프로젝트 2개만 구글 클라우드 프로젝트 ID·시크릿 일부·영상 ID를 가렸습니다.
- 이 파일들은 **복사본**입니다. claude.ai에서 고쳐도 자동 반영되지 않습니다. 이 프로젝트 2개는 Claude가 갱신할 때마다 같이 갱신합니다(`CLAUDE.md` 규칙).
- **도표(mermaid)**: 9개 파일(국내주식현상, 랭체인·랭그래프·RAG 3개, 모의면접 재구축 명세서, 바이브코딩 블로그 현황판, 온프리미스 2개, 이력서 제출 절차)는 claude.ai가 제공하는 도표 프로그램(`/_runtime/mermaid-…`)을 쓰기 때문에, **내 PC에서 파일로 열면 도표가 그림이 아니라 글자(코드)로 보입니다.** Claude에서 아티팩트로 다시 발행하면 그림으로 보입니다(같은 방식으로 만들어졌기 때문이며, 다시 발행한 결과는 확인하지 못했습니다).
- `영상 제작 단계별 가이드.html`은 인터넷의 `marked` 글꼴·변환 프로그램을 불러옵니다. **인터넷이 연결되지 않으면 본문이 비어 보입니다**(이 환경의 시험에서 그랬습니다).
- 일부 파일은 휴대폰 폭(400px)에서 가로로 넘칩니다(원본 아티팩트도 같습니다: FINAL-PROJECT-NEW, 모의면접 스펙 비교, 프로젝트 전체 지도, 바이브코딩 블로그 현황판).
- 체크리스트(`내할일`)의 체크 표시는 보는 브라우저에만 저장되며 파일에 들어 있지 않습니다.
