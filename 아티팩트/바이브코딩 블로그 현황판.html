최근 처리한 이슈 — 배포 전 발견된 결함 2건

10단계 addendum과 로컬 Postgres 전환 과정에서 실제 Neon 배포를 막았을 결함 2건을 발견해 당일 해소함.
2026-09-28
DEF-10-06 (Critical) — 실배포 시 빌드 100% 크래시
10단계 addendum이 실제 Postgres(Neon 재현)로 build.sh를 실행해 legal.0003 마이그레이션에서 트랜잭션 abort 크래시를 2회 재현. 근본원인: wagtail.search 의존성 누락으로 검색색인 테이블 생성 전에 INSERT 시도.
2026-09-29
DEF-10-06 수정 — wagtailsearch 의존성 명시
로컬 Postgres 16(운영과 동일 엔진)에서 수정 전/후 대조 재현으로 검증. 전체 테스트 114/114 통과. 10-deploy-test.md PASS로 갱신.
2026-09-29
데이터 이전 부작용 — content_type ID 불일치
SQLite→Postgres 데이터 이전을 PK 그대로 복사하는 방식으로 수행해, 동일 정수 ID가 DB마다 다른 모델을 가리키게 됨(예: 글이 태그로 오인식). 실제 글 상세 페이지 크래시로 발견.
2026-09-29
자연키 기반 재이전으로 해소
dumpdata --natural-foreign으로 재이전(앱/모델 이름 기준 자동 재매핑). 전체 Page·Revision·PageLogEntry를 모델별로 집계해 오염 0건 확인, 브라우저 실측 + 테스트 114/114 재확인.

12단계(실배포) 전 남은 작업

애플리케이션은 배포 준비가 됐지만, 실제 벤더 계정/자격증명은 아직 하나도 발급되지 않은 상태.
1

Cloudflare R2

  • 버킷 2개 — media-public, backup-private
  • API 토큰 버킷별 분리 발급 권장
2

Neon PostgreSQL

  • 프로젝트 생성, Render와 가까운 리전
  • pooled connection string 사용 확인
3

Render 웹서비스

  • render.yaml Blueprint로 신규 생성
  • 환경변수 25개 입력(★10개는 .env.example 누락분)
4

GitHub Actions Secrets

  • 백업 워크플로용 6개 시크릿
  • 미입력 시 워크플로가 명시적으로 실패 처리
